# Sprint M2.0 — Contract Authority Implementation Report

Date: 2026-07-05  
Scope: Contract Authority only; schema remains 1.0.

## 1. Executive Summary

M2.0 makes infrastructure.contract.json the authoritative runtime infrastructure artifact. Publishing is the sole production writer. A shared IDeploymentPackageContractReader now serves Publishing verification, package validation, DRV, and Runtime Agent.

The reader validates presence, checksum coverage, SHA-256 integrity, deserialization, supported version 1.0, service identity, and byte-for-byte canonical equality after deserialization. Failures use deterministic ICA001–ICA009 diagnostics. Runtime Agent and DRV no longer call InfrastructureContractBuilder.Build; they pass the published contract into the unchanged provisioning pipeline.

Schema v2, Requirement/Capability modeling, Bootstrap, Compose, Kubernetes, Specification-as-Data, and provisioning redesign remain out of scope.

## 5. Runtime Consumer Matrix

| Component | Previous behavior | New behavior |
|---|---|---|
| Publishing | General bundle writer generated aggregate | Dedicated writer, checksum sealing, immediate consume proof |
| Runtime Agent | Rebuilt from bundle | Reads exact package contract; integrity failure blocks deployment |
| DRV | Rebuilt from bundle | Reads exact package contract before simulation |
| Package verifier | Generic checks only | Aggregate integrity/version/equality checks |
| Package validator | Parsed package and bundle | Shared aggregate validation mandatory |
| Provisioning pipeline | Received rebuilt aggregate | Receives published aggregate; pipeline design unchanged |

## 6. Removed Technical Debt

- T6 decorative artifact: the aggregate is canonical and consumed.
- T7 dual construction: Runtime Agent and DRV builder call sites are deleted.
- General bundle serialization is no longer a hidden second writer.
- Aggregate loading, deserialization, integrity, version, caching, and equality logic are centralized.
- Runtime network resolution reads the published aggregate.
- Legacy bundle compatibility remains isolated and is not an infrastructure reconstruction path.

## 7. Compatibility Assessment

The model and JSON settings remain M1 schema 1.0. Completed-M1 packages containing a canonical checksum-sealed aggregate remain compatible.

Packages predating aggregate emission cannot be adapted without violating the explicit missing-contract and no-reconstruction rules. They fail deterministically with ICA002 and must be republished.
