## Business Terms

| Term | Definition |
|------|------------|
| **Always Audit Ready** | Continuous readiness vs pre-audit crunch |
| **Accreditation** | Formal recognition (e.g. NABH) |
| **Obligation** | Framework-derived requirement tracked per org/hospital |
| **Objective Element (OE)** | Granular assessable unit under a standard |
| **Readiness** | Quantified preparedness score from snapshots/rules |
| **Maturity Stage** | Governance gate in compliance journey |
| **Deficiency** | Governed gap record (post-promotion or evaluation) |
| **Finding** | Operational observation before/alongside deficiency |
| **CAPA** | Corrective and Preventive Action |
| **DCC** | Deficiency Command Center UX |
| **Verification** | Evidence approver sign-off |
| **Persona** | Copilot behavioral mode (e.g. Accreditation Coach) |

| Term | Definition |
