## From Accreditation Tool to Operating System

Today PRAMAN **centers NABH** journey execution with evidence, findings, and maturity governance. The architecture (multi-framework policies, KnowledgeBase graph, persona Copilot) supports **extension** without replacing the core SSOT model.

## Enterprise AI Vision

1. **Deterministic layer** remains SSOT for regulated recommendations.
2. **LLM layer** explains, drafts language, answers questions in sidebar.
3. **Tool execution** only through proposal framework.
4. **Observability** merges Copilot effectiveness with quality outcomes.
