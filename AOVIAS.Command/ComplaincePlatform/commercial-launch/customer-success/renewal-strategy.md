# Renewal Strategy

**Commercial model:** Manual license keys — see [`../licensing/renewal-process.md`](../licensing/renewal-process.md).  
**No** in-app payments in v1.0.0.

## Motions

1. **Value confirmation** — ROI worksheet + QBR scorecard before asking for PO.  
2. **Risk removal** — Close open S1/S2; ensure license not already in uncontrolled Grace.  
3. **Expansion** — Seats, `ai.assist`, `governance.risk`, `ace.insights` as change-order keys.  
4. **Multi-year** — Longer `validDays` on issued key after Finance approval.

## Timeline playbook

| When | CSM action |
|------|------------|
| T−90 | Confirm sponsor + economic buyer |
| T−60 | QBR with renewal section; draft commercial ask |
| T−45 | ROI + success metrics pack to buyer |
| T−30 | PO / paperwork; alert Support of date |
| T−14 | Issue key; walk activation |
| T−7 | Verify Active + heartbeat |
| T+0 | If slipped: Grace communication (T4 template); daily chase |

## Save plays

| Risk | Play |
|------|------|
| Low adoption | Free enablement sprint; executive workshop |
| Budget slip | Short extension key (`validDays` small); document exception |
| Champion left | Re-map sponsor within 10 business days |
| Competitor eval | Security + architecture whitepapers; live scenario demo |

## Handoffs

- Sales owns quote; CSM owns outcome narrative.  
- Support owns activation failures.  
- Product owns entitlement gaps (feature missing vs not entitled).
