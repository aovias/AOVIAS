# Scenario — Audit Prep

**Duration:** ~8 minutes  
**Persona:** Quality Manager → Auditor view  
**Entitlements:** `core.compliance`

## Story

External or internal audit should consume packages, not WhatsApp ZIP files.

## Steps

1. From QM context, open Audit management / auditor workspace entry point.  
2. Select a demo audit or assessment package tied to seeded journeys.  
3. Show evidence linkage and journey status the auditor would see.  
4. Switch to Auditor persona (or explain permission boundary) and open read-focused workspace.  
5. Highlight what is intentionally not editable for auditors.

## Say this

“We assemble the story the assessor will walk—status, evidence, and gaps—without breaking lifecycle locks.”

## Backup if UI missing a package

Walk the journey list filtered to Submitted/ready elements and describe the auditor workspace capability from the Phase 14 report narrative.

## Success signal

Prospect asks about export or assessor guest access (capture as follow-up).
