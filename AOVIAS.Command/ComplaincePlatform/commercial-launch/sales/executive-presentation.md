# Executive Presentation — AOVIAS Command

**Audience:** CEO / Medical Director / CFO (12 minutes)  
**Goal:** Secure sponsorship for a quote-ready evaluation

## Opening (1 min)

Accreditation readiness is a leadership risk, not a paperwork hobby. AOVIAS Command gives one accountable system for compliance, CAPA, and governance.

## Four slides worth saying aloud

### 1. Visibility

Today: green cells in spreadsheets.  
With AOVIAS: journey status, evidence gaps, CAPA aging, and (if licensed) ACE insights on one executive surface.

### 2. Control

Evidence locks when submitted. Roles are explicit. Auditors get packages, not WhatsApp folders.

### 3. Investment

Quote-based packages map to entitlements—buy Core first, add AI or Governance when policy and budget allow. No surprise self-serve charges in product.

### 4. Path

Demo → 2-week technical validation → implementation timeline → go-live before assessment window.

## CFO questions (pre-baked answers)

| Question | Answer direction |
|----------|------------------|
| CapEx vs OpEx? | Annual license OpEx; implementation often one-time |
| ROI? | Use ROI worksheet with their FTEs |
| Lock-in? | Data in customer SQL catalogs; export/reporting discussed in MSA |
| AI risk? | Advisory-only; entitlements can be off |

## Close

Ask for: named QM sponsor, IT sponsor, accreditation date, and permission to schedule the guided demo.
