# Pricing One-Pager — AOVIAS Command v1.0.0

**Model:** Quote-based annual license + optional implementation. **No online payment** in v1.0.0.

## Packages → entitlements

| Package | Entitlements | Narrative price band* |
|---------|--------------|------------------------|
| **Command Core** | `core.compliance` | Entry hospital program |
| **Command + AI Assist** | `core.compliance` + `ai.assist` | Core + grounded assistant |
| **Command Governance** | `core.compliance` + `governance.risk` | Core + risk/incidents/docs/MR |
| **Command Enterprise** | `core.compliance` + `ai.assist` + `governance.risk` + `ace.insights` | Full stack |

\*Internal bands live in commercial ops; do not publish dollar amounts on the website without approval. Related codes `core.documents` / `core.capa` may appear on issued keys.

## What the quote includes

- License key, seats, heartbeat/grace policy
- Standard support tier (define in MSA)
- Access to published guides

## What is typically separate

- Implementation / data migration
- Extra environments (prod + staging)
- Premium support / dedicated CSM
- Custom framework content authoring

## Sales motion

1. Qualify accreditation date + bed scale + IT hosting preference  
2. Demo via runbook  
3. Confirm entitlement package  
4. Issue proposal from template  
5. Activate license post-MSA
