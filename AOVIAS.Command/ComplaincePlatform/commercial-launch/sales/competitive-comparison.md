# Competitive Comparison — AOVIAS Command

**Positioning note:** Use as a conversation aid, not a public attack sheet. Prefer discovery questions over feature bingo.

## Comparison axes

| Axis | AOVIAS Command | Typical spreadsheet QMS | Generic GRC cloud | Point AI chatbot |
|------|----------------|-------------------------|-------------------|------------------|
| Healthcare accreditation workflows | Purpose-built journeys + evidence lock | Manual | Often horizontal | None |
| CAPA / deficiency SSOT | Yes (platform domain) | Fragmented | Varies | No |
| Entitlement licensing | Feature codes + seats | N/A | Subscription SKUs | Seat/token |
| Grounded AI | Entitlement-gated AIL | None | Rare / bolt-on | Ungrounded risk |
| On-prem / customer VPC path | Package + compose deploy | N/A | Often SaaS-only | SaaS |
| Honest v1.0.0 limits | No self-serve payments; HA is ops-owned | — | — | — |

## Win themes

1. **Lifecycle integrity** — state machine owned transitions, not status dropdown chaos  
2. **Hospital roles** — QM / Dept Head / Owner / Auditor homes  
3. **Governance depth** — risk + incidents + documents + MR when entitled  
4. **AI accountability** — assist without pretending to be the auditor  

## Loss / watch-outs

- Buyer wants pure consumer SaaS checkout → defer; we are quote-led  
- Buyer needs certified device / EHR clinical documentation → out of scope  
- Buyer demands named logos → use anonymized samples until pilots sign  

## Discovery questions

- Which accreditation cycle date is immovable?
- Who owns evidence today (roles + tools)?
- Is AI allowed by hospital policy? Which data classes are forbidden?
- Prefer SaaS, private cloud, or on-prem SQL?
