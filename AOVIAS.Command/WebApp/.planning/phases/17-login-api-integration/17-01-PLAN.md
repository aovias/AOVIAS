<task type="auto">
  <name>Task 2: Update AuthService to extend BaseApiService</name>
  <files>src/app/core/auth/services/auth.service.ts</files>
  <action>
    Refactor AuthService to follow PRAMAN architecture:

    1. Remove direct HttpClient injection
    2. Make AuthService extend BaseApiService
    3. Update login() method:
       - Use `this.post<LoginResponse>()` from BaseApiService (not `this.http.post()`)
       - Change endpoint from `/auth/login` to `/identity/login`
       - The ApiResponseInterceptor will automatically unwrap the response, so login() receives LoginResponse directly
       - Map `response.token` to `accessToken` when saving to SessionService (backend returns "token" but we store as "accessToken")
    4. Update refreshToken() method:
       - Use `this.post<LoginResponse>()` from BaseApiService
       - Change endpoint from `/auth/refresh` to `/identity/refresh`
       - Map `response.token` to `accessToken` when saving
    5. Import LoginRequest and LoginResponse from models
    6. Remove LoginRequest and LoginResponse interfaces from this file (they're now in models)

    IMPORTANT: Do NOT call HttpClient directly. All HTTP calls must go through BaseApiService methods.
  </action>
  <verify>
