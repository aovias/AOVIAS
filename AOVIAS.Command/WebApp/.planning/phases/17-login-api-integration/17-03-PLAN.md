<task type="auto">
  <name>Task 2: Integrate LoginComponent with AuthService and update contexts</name>

  <action>
    Update LoginComponent to integrate with AuthService:

    1. Import and inject:
       - `AuthService` from `src/app/core/auth/services/auth.service`
       - `Router` from `@angular/router`
       - `UserContextService` from `src/app/core/services/user-context.service`
       - `ComplianceContextService` from `src/app/core/services/compliance-context.service`
       - `SessionService` from `src/app/core/auth/session.service`
       - `LoggerService` from `src/app/core/services/logger.service` (for logging, not console.log)

    2. Update `onSubmit()` method:
       - Get email and password from signals
       - Set `isLoading.set(true)`
       - Call `authService.login({ email: this.email(), password: this.password() })`
       - Subscribe to the Observable:
         - On success:
           - Update SessionService with organizationId, hospitalId, userId from response
           - Update UserContextService: `userContext.setUser({ id: response.userId, email: response.email, username: response.email, roles: [response.role] })`
           - Update ComplianceContextService: `complianceContext.setOrganizationId(response.organizationId)` and `setHospitalId(response.hospitalId)`
           - Log success using LoggerService: `logger.info('Login successful')`
           - Navigate to `/app/dashboard`: `router.navigate(['/app/dashboard'])`
         - On error:
           - Set `isLoading.set(false)`
           - Log error using LoggerService: `logger.error('Login failed', error)`
           - Error handling will be added in next plan (Plan 04)

    3. Remove the mock setTimeout logic from current onSubmit()

    IMPORTANT: Use LoggerService for all logging (no console.log). Handle errors gracefully but detailed error UI will be in next plan.
  </action>

    Success path updates all context services and navigates to dashboard

    LoggerService is used for logging (no console.log)
  </verify>
