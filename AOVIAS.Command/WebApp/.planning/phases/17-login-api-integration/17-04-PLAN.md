  <files>src/app/login/login.component.ts</files>
  <action>
    Add error handling with Material SnackBar:

    1. Import:
       - `MatSnackBar` from `@angular/material/snack-bar`
       - `MatSnackBarModule` in component imports array

    2. Inject MatSnackBar in constructor or using inject():
       - `private snackBar = inject(MatSnackBar)`

    3. Create error message mapping method:
       ```typescript
       private getErrorMessage(error: HttpErrorResponse): string {
         if (error.status === 401) {
           return 'Invalid email or password';
         } else if (error.status >= 500) {
           return 'Unable to login. Please try again.';
         } else if (error.status === 0 || error.name === 'NetworkError') {
           return 'Network error. Check connection.';
         }
         return 'Login failed. Please try again.';
       }
       ```

    4. Update onSubmit() error handler:
       - In the catchError or error callback:
         - Get error message using `getErrorMessage(error)`
         - Show SnackBar: `this.snackBar.open(message, 'Close', { duration: 5000, horizontalPosition: 'center', verticalPosition: 'top' })`
         - Set `isLoading.set(false)`
         - Log error: `this.logger.error('Login failed', error)`

    IMPORTANT: Handle HttpErrorResponse types. Use appropriate error status codes for message mapping.
