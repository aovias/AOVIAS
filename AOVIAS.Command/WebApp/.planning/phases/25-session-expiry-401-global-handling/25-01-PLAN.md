# Plan 25-01: Session expiry, 401 handling & single-flight refresh (observable errors, no loops)

## Objective

Refactor **authentication + HTTP interceptors** so that:

1. **`POST /identity/refresh`** failures are handled with **RxJS `catchError`** on the **refresh Observable** — **not** with **`try/catch`** as the primary path for HTTP/network errors.
2. **Any** refresh failure is **non-recoverable** for staying logged in: **401, 403, 5xx (incl. 503), status 0 / network / timeout** → **one** centralized logout, clear caches, redirect to login.
3. **Single-flight refresh**: concurrent **401**s share **one** in-flight refresh; **queue** behavior via **shared Observable** (all waiters replay or error together).
4. **No infinite loops**: **`/identity/refresh`** failure never triggers another refresh attempt; **no** unbounded retries.
5. **UX**: optional **“Session expired…”** toast; **no** misleading **“Failed to load… (timeout/network)”** for session/auth outcomes.
6. **Logging**: structured logs on refresh failure (**status**, **endpoint URL**, error body summary if safe).

**Preserves:** token storage model, API contracts, envelope handling.

## must_haves (goal-backward)

- [ ] **`catchError`** on the **refresh** stream handles **all** async refresh failures (including **503**); **`try/catch`** only for **synchronous** preconditions (e.g. missing refresh token), or eliminate by using **`defer` + `throwError`** inside Observable.
- [ ] **Single-flight** refresh: **one** HTTP refresh at a time; concurrent requests **await** the same refresh result.
- [ ] **Any** refresh failure → **`SessionExpiryCoordinator`** (or equivalent) → **`AuthService.logout()`** + optional toast + **Router** to **`/login`** **once** (idempotent).
- [ ] **No** refresh retry loop when **`/identity/refresh`** returns error.
- [ ] **Logging** for refresh failures: **HTTP status** (or **0**), **`/identity/refresh`** URL, optional **`LoggerService`** at **warn/error**.
- [ ] Feature layers (e.g. hospital profile) **do not** show generic timeout/network copy for **401/403** when global session handling applies.
- [ ] **`ng build`** passes.

## Verification criteria (manual / QA)

- **503** on **`/identity/refresh`** → **single** logout, **redirect** login, **log** contains status + refresh endpoint.
- **Parallel** **401**s (e.g. two tabs) → **one** refresh HTTP call, then **both** requests retried or **both** fail after logout.
- **401** → refresh succeeds → API still **401** → **no** second refresh (loop prevention).
- **Network error** (status **0**) on refresh → **logout** + login.
- No **“Failed to load departments (timeout or network…)”** when failure is **401/403** session-related.

## Notes

- **`HttpContext`** **`SKIP_AUTH_REFRESH`** (or equivalent) is the **standard** way to avoid **retry → 401 → refresh** loops; add to **retried** request only.
- **Login** page may read **`sessionExpired`** query for inline copy (optional small follow-up).
- **Resource** **403** (forbidden but valid session) is **out of scope** unless product equates it with session — **refresh**-path **403** is always terminal.
