# Phase 45 — Plan 01: Login two-column shell (2:1)

## Goal (backward verification)

`LoginComponent` presents a **desktop two-column** layout with **left ⅔ primary** (credential flow) and **right ⅓ secondary** (AI Security Assistant + biometric), **without** adding/removing controls, **without** changing `loginForm` or `onSubmit` / SSO / biometric method bodies. **Visual/layout only.**

## must_haves

- [ ] **MH1** — Same **number and type** of interactive elements as before (email, password, toggle, remember, forgot link, submit, 2× SSO, signup link, biometric button, support links).
- [ ] **MH2** — **Left column** vertical order: Welcome title → email → password → remember/forgot row → Sign In → divider → Microsoft & Google (horizontal) → Create Hospital Account link → (footer meta lines retained per spec).
- [ ] **MH3** — **Right column** vertical order: AI Security Assistant card (badge + status) → Quick Secure Login (biometric) block; visually separated from left.
- [ ] **MH4** — **Desktop** width ratio **2:1** (e.g. `grid-template-columns: minmax(0, 2fr) minmax(0, 1fr)` or flex `2` / `1`).
- [ ] **MH5** — **Mobile:** primary column content **first**, secondary **below**; no horizontal scroll at default viewport.
- [ ] **MH6** — `ng build` succeeds; **no** edits to `login.component.ts` except if absolutely required for a11y (prefer none).
