# 31-01: Dynamic User Name in Header — Model Update, Member Lookup & Binding

## Objective
Replace the hardcoded "Dr. Sarah Johnson" text in the header user menu with the logged-in user's actual name, sourced from the `members[]` array of the `organization-detail` API response. Update the `OrganizationMember` interface to reflect the full API contract.

## Research Summary

**Current state:**
- `header.component.ts` (line 137) contains `<span class="user-name">Dr. Sarah Johnson</span>` — a static string.
- `OrganizationMember` interface in `organization.service.ts` only has `id`, `userId`, `role`, `createdAt`.
- The API response includes additional fields per member: `firstName`, `lastName`, `email`, `phoneNumber`, `alternatePhoneNumber`, `profilePicUrl`, `preferences`.
- `SessionService.getUserId()` returns the logged-in user's `userId` from `localStorage`.
- `OrganizationService` already loads and caches `OrganizationDetails` (which includes `members[]`).
- `HeaderComponent` currently injects `ThemeService`, `AuthService`, `Router` only.

**Approach:** Update the `OrganizationMember` model, add a `getMemberByUserId()` helper on `OrganizationService`, inject `OrganizationService` + `SessionService` into the header, and reactively bind the display name.

## Tasks

<task id="01" name="Update OrganizationMember interface">
### Extend `OrganizationMember` to match full API response
**File:** `src/app/core/services/organization.service.ts`

Update the existing `OrganizationMember` interface to include all fields from the API response:

```typescript
export interface OrganizationMember {
  id: string;
  userId: string;
  /** Canonical role id; use `RoleRegistryService.labelOf` / `roleLabel` pipe in UI. */
  role: string;
  firstName: string | null;
  lastName: string | null;
  email: string | null;
  phoneNumber: string | null;
  alternatePhoneNumber: string | null;
  profilePicUrl: string | null;
  preferences: unknown | null;
  createdAt: string;
}
```

### Add helper method `getMemberByUserId(userId: string)`
Add to `OrganizationService`:

```typescript
getMemberByUserId(userId: string): OrganizationMember | null {
  const members = this.organizationSubject.value?.members ?? [];
  return members.find((m) => m.userId === userId) ?? null;
}
```

### Add helper method `getLoggedInMemberDisplayName()`
Add to `OrganizationService`:

```typescript
getLoggedInMemberDisplayName(userId: string | null): string {
  if (!userId) return '';
  const member = this.getMemberByUserId(userId);
  if (!member) return '';
  const parts = [member.firstName, member.lastName].filter(Boolean);
  return parts.join(' ');
}
```

### Verification
- [ ] `OrganizationMember` interface includes `firstName`, `lastName`, `email`, `phoneNumber`, `alternatePhoneNumber`, `profilePicUrl`, `preferences`.
- [ ] `getMemberByUserId()` method returns the matching member or `null`.
- [ ] `getLoggedInMemberDisplayName()` returns `"firstName lastName"` with null-safe handling (skips null/empty parts).
</task>

<task id="02" name="Bind dynamic user name in HeaderComponent">
### Replace static text with reactive user name
**File:** `src/app/core/layout/header.component.ts`

1. **Add imports** for `OrganizationService` and `SessionService`:
   ```typescript
   import { OrganizationService } from '../services/organization.service';
   import { SessionService } from '../auth/session.service';
   ```

2. **Inject services** in the component class:
   ```typescript
   private readonly organizationService = inject(OrganizationService);
   private readonly sessionService = inject(SessionService);
   ```

3. **Add a `userName` signal** initialized from the organization data:
   ```typescript
   readonly userName = signal<string>('');
   ```

4. **Implement `OnInit`** to resolve the user name once organization data is available:
   ```typescript
   implements OnInit
   // ...
   ngOnInit(): void {
     this.resolveUserName();
   }

   private resolveUserName(): void {
     const userId = this.sessionService.getUserId();
     const displayName = this.organizationService.getLoggedInMemberDisplayName(userId);
     if (displayName) {
       this.userName.set(displayName);
       return;
     }
     // If org data not loaded yet, subscribe and resolve when available
     this.organizationService.organization$
       .pipe(
         filter((org) => org !== null),
         take(1),
         takeUntilDestroyed(this.destroyRef),
       )
       .subscribe(() => {
         const name = this.organizationService.getLoggedInMemberDisplayName(userId);
         this.userName.set(name || '');
       });
   }
   ```

5. **Add required imports** for reactive operators:
   ```typescript
   import { DestroyRef, inject, OnInit } from '@angular/core';
   import { takeUntilDestroyed } from '@angular/core/rxjs-interop';
   import { filter, take } from 'rxjs';
   ```

6. **Update template** — replace the static text:
   ```html
   <!-- Before -->
   <span class="user-name">Dr. Sarah Johnson</span>

   <!-- After -->
   <span class="user-name">{{ userName() }}</span>
   ```

7. **Update the user avatar** to show initials when name is available (optional UX enhancement):
   ```html
   <div class="user-avatar">
     @if (userName()) {
       <span class="avatar-initials">{{ userName().charAt(0) }}</span>
     } @else {
       <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor">
         <path d="M20 21v-2a4 4 0 00-4-4H8a4 4 0 00-4 4v2M12 11a4 4 0 100-8 4 4 0 000 8z" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"/>
       </svg>
     }
   </div>
   ```

   Add CSS for initials:
   ```css
   .avatar-initials {
     font-size: 14px;
     font-weight: 600;
     color: white;
     text-transform: uppercase;
   }
   ```
