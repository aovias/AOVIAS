## Objective

Create a modern, modal-based hospital selector popup that replaces the old header dropdown. The modal opens centered with a smooth animation, displays a radio-button list of hospitals, supports single selection with visual highlighting, and provides Confirm/Cancel actions.

## Context

Angular Material `MatDialog` is already used in the project (see `shared/ui/dialog/` and `shared/ui/confirmation-dialog/`). The new hospital selector dialog will follow the same pattern but with a custom template featuring:
- Radio button list of hospitals (each with name, org, optional icon)
- Single selection with visual highlighting
- Confirm and Cancel buttons
- Full-screen semi-transparent overlay
- Smooth scale/fade animation

The dialog receives the current hospital list and selected hospital ID as input data, and returns the newly selected hospital ID on confirm.

- `Confirm Selection` button disabled if no change made (same hospital re-selected) or no selection
- Non-onboarded hospitals shown but disabled with a badge
- Custom radio buttons for consistent styling across themes
- Checkmark icon appears on selected item for extra visual feedback

<task id="29-03-04" title="Implement dialog component logic">
**File:** `src/app/shared/ui/hospital-selector/hospital-selector-dialog.component.ts`

Component class:

```typescript
export class HospitalSelectorDialogComponent {
  readonly selectedId = signal<string | null>(null);

  constructor(
    public readonly dialogRef: MatDialogRef<HospitalSelectorDialogComponent>,
    @Inject(MAT_DIALOG_DATA) public readonly data: HospitalSelectorDialogData,
  ) {
    // Initialize with current selection
    this.selectedId.set(data.selectedHospitalId);
  }

  selectHospital(hospital: HospitalSelectorItem): void {
    if (!hospital.isOnboarded) return;
    this.selectedId.set(hospital.id);
  }

  onConfirm(): void {
    if (!this.selectedId() || this.selectedId() === this.data.selectedHospitalId) return;
    this.dialogRef.close(this.selectedId());
  }

  onCancel(): void {
    this.dialogRef.close(null);
  }
}
```

Key behaviors:
- `selectedId` signal initialized with current selection
- `selectHospital` ignores non-onboarded hospitals
- `onConfirm` returns selected hospital ID; closes with `null` on cancel
- Confirm blocked if no new selection
</task>
