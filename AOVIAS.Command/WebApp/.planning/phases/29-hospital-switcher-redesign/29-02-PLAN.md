## Objective

Add a hospital display card component above the sidebar navigation that shows the currently selected hospital name, organization name, a hospital icon/avatar, and a clickable change icon. This card replaces the header-based hospital selector as the primary hospital context indicator.

## Context

The sidebar component (`core/layout/sidebar.component.ts`) currently renders only the `<nav class="sidebar-nav">` element. The hospital card needs to be placed **above** this nav, inside the same `<aside class="sidebar">` element, so it shares the sidebar width (280px) and scroll behavior is only on the nav portion.

The card must:
- Read hospital data from `OrganizationService` and `ComplianceContextService`
- Display hospital name (bold), organization name (subtle), hospital avatar/icon, and a change icon
- Emit a click event on the change icon that will open the hospital selector modal (Plan 29-03)

<task id="29-02-03" title="Add component logic for hospital data and change action">
**File:** `src/app/core/layout/sidebar.component.ts`

Add the following to the component class:

1. **Inject services:**
   - `OrganizationService` — to get hospitals and organization name
   - `ComplianceContextService` — to read current `hospitalId$`
   - `MatDialog` — to open the hospital selector modal

2. **Add signals:**
   - `selectedHospitalName = signal('No hospital selected')`
   - `selectedOrganizationName = signal('Organization')`

3. **Add `OnInit` lifecycle:**
   - Subscribe to `ComplianceContextService.hospitalId$`
   - On each emission, look up the hospital in `OrganizationService.getHospitals()` by id
   - Update `selectedHospitalName` and `selectedOrganizationName` signals
   - If no hospitalId, show defaults

4. **Fallback initialization:**
   - On init, also check `OrganizationService.getOrganization()` for cached data
   - If not cached, subscribe to `OrganizationService.loadOrganizationDetails()` once
   - After org loads, if `ComplianceContextService.getHospitalId()` is set, resolve display names

5. **Add `onChangeHospital()` method:**
   - Opens the hospital selector dialog (from Plan 29-03)
   - On dialog close with result, call `AppContextService.switchHospital(selectedId)`
   - This will be wired in Plan 29-04 once the dialog exists; for now, add the method with a TODO comment

6. **Add imports:** `OnInit`, `inject`, `signal`, `DestroyRef`, `takeUntilDestroyed`
</task>
