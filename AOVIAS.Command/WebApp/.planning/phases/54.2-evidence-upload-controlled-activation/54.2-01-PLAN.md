# Phase 54.2 — Wave 1: Feature flag + file picker + drag/drop

## Goal

Add **`environment.enableOeWizardEvidenceUpload`** (or equivalent name) defaulting **false** in prod. When **true** and the Evidence step is **not** read-only: replace “upload disabled” snackbar-only behavior with a **hidden** `<input type="file">` ( **`multiple`** ), **click** on dropzone triggers `input.click()`, **basic drag-and-drop** on the dropzone fills `evidenceUploadFiles` via existing `handleFileSelect` / `handleBulkSelect`. When flag is **false**, preserve Phase 53–54 behavior (no picker, snackbar + tooltip). **No** HTTP calls in this wave.
