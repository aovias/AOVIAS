# Phase 48 — Plan 03: Execution workspace — chapters, standards, OE rows, context panel

## Phase goal (backward)

**Execution screen** three-column workspace uses **policy** to show/hide **badges**, **risk labels**, **issue counts**, **compliance / change / maturity** indicators, and to set **read-only** interaction on OE rows in FinalAudit—**without** new panels or routes.

## must_haves

- [ ] **Chapter panel**: Self hides issue badge; Internal highlights high-risk; Final shows PASS/FAIL indicator **using existing text/badge slots** (mock PASS/FAIL from VM until API); Surveillance “changed since last audit”; ReAccreditation maturity/excellence indicator (mock label if no data).
- [ ] **Standard card**: Self hides bulk open-issues line; Internal shows evidence gaps; Final swaps issues for compliance status; Surveillance shows change arrow + previously failed; ReAccreditation excellence badge.
- [ ] **OE rows**: Self hides risk chips; shows status + optional score; Internal shows risk + classification + NC highlight; Final **read-only** (no inline edit affordances); Surveillance changed/unchanged; ReAccreditation full classification + excellence line.
- [ ] **Context panel**: Evidence upload / tasks / quick actions **visibility and disabled** per policy; tooltips for disabled reasons.
- [ ] `ng build` passes.
