<task>
  <name>Create OnboardingStore with Signals</name>
  <files>src/app/features/onboarding/state/onboarding.store.ts</files>
  <action>
    1. Import `Injectable`, `inject`, `signal` from `@angular/core`
    2. Import `Organization`, `Hospital`, `AdminUser`, `OnboardingRequest` models
    3. Create `@Injectable({ providedIn: 'root' })` class `OnboardingStore`
    4. Create signals:
       - `organization = signal<Organization | null>(null)`
       - `hospital = signal<Hospital | null>(null)`
       - `adminUser = signal<AdminUser | null>(null)`
       - `currentStep = signal<number>(1)`
    5. Implement methods:
       - `setOrganization(org: Organization): void` - sets organization signal
       - `setHospital(hosp: Hospital): void` - sets hospital signal
       - `setAdminUser(user: AdminUser): void` - sets adminUser signal
       - `setCurrentStep(step: number): void` - sets currentStep signal
       - `buildRequestPayload(): OnboardingRequest` - combines all signals into request payload
       - `reset(): void` - clears all signals and resets to step 1
  </action>
  <verify>
    - Store uses Angular Signals (not BehaviorSubject)
    - All signals properly typed
    - `buildRequestPayload()` returns properly structured OnboardingRequest
    - `reset()` clears all state
    - TypeScript compiles
  </verify>
  <done>OnboardingStore created with Signals</done>
</task>
