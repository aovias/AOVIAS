# Plan 02 — Fullscreen wizard shell, stepper, steps, integration

## Goal (phase)

Implement the **OE Execution fullscreen wizard** per **44-DESIGN-SPEC.md**: overlay shell, stepper, five step views (presentational + wired to store/VM), persistent context panel, **Start/Execute Journey** entry from the Journey Context Panel, **close + unsaved guard**, **resume** persistence (mock/session until API), **responsive** layout hooks, **token-only** SCSS, **OnPush**, **keyboard/focus** behavior aligned with `DESIGN_RULES.md`.

## must_haves

- [ ] **Fullscreen overlay** component (or dialog config) covering viewport; backdrop; close with **confirm** when dirty.
- [ ] **Stepper** with five steps; visual states: locked, active, completed; click navigates only when unlocked.
- [ ] **Main** area swaps content; scroll via **`praman-scrollbar`** where applicable.
- [ ] **Right context** panel: OE summary, progress, current step, status, **Next action** copy (from VM/store), quick actions (stub handlers acceptable).
- [ ] **Locking logic** implemented in store/service: Understand → Execute → Evaluate → Improve (conditional) → Complete.
- [ ] **Persist** wizard step + key flags (sessionStorage namespaced per existing isolation patterns).
- [ ] **Responsive:** desktop 2-column; tablet context collapse pattern; mobile stacked / horizontal stepper — at minimum CSS breakpoints using **`--bp-*`**.
- [ ] **Themes:** light/dark via existing theme tokens only.
- [ ] **a11y:** focus trap on open; `aria-current` / progress semantics on stepper; logical heading order.
- [ ] **`ng build`** passes.
