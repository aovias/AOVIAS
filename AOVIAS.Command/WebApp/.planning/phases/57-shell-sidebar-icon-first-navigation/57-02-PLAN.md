# Plan 02 — Sidebar component: icon-first desktop layout, tooltips, ripple, hybrid rail

## Goal (wave)

Refactor `SidebarComponent` presentation so **icons are the primary affordance** for **all** primary nav rows (consistent with existing **quick-action** tile language), with **labels** available as **secondary** (full width mode), **on hover** (hybrid compact mode), or **tooltip** (when labels hidden). Add **MatRipple** (or directive equivalent) to interactive rows. Preserve **routerLinkActive**, **disabled** states, **submenu** expansion, and **Operational Mode** / hospital **context panel** behavior.

## must_haves

- [ ] **Desktop (≥768px):** Nav rows use **icon-leading** layout; labels visible when sidebar not in “compact icon” mode; **hybrid mode** either (a) expands rail on **:hover** to show section + row labels, or (b) shows **flyout** label — pick one implementation; document in `DESIGN_RULES.md` shell section.
- [ ] **Tooltip:** `matTooltip` shows **full label** (or `tooltip` override) when labels are hidden or collapsed; respect `MatTooltip` **delay** for hover (desktop).
- [ ] **Active state:** Existing **left accent** + **brand soft background** preserved or refined with **tokens only** (no new arbitrary hex); **primary** Journey row remains visually emphasized.
- [ ] **Ripple / feedback:** `MatRippleModule` imported; **menu-item** anchors/buttons show ripple on activation (`matRipple` + ripple color from `--color-brand-primary` mix or documented token).
- [ ] **Icon size:** CSS targets **20–24px** via tokens (e.g. `--icon-size-nav` if added to foundation/theme) — **no** hardcoded px in feature if project forbids (follow `DESIGN_RULES.md`).
- [ ] **Quick-actions strip:** Implement **57-01** decision — if removed, ensure **Tasks / Evidence / Findings** (and related) remain reachable **only** via main nav with **equal or better** discoverability (tooltip + aria).
- [ ] **Submenus:** When parent is icon-first, **expanded** submenu still shows **text** child labels; collapsed sidebar continues to hide submenus (existing behavior) or documents **exception** if changed.
- [ ] **Accessibility:** Each icon-only interactive control exposes **`aria-label`** (English) = user-facing nav name.
