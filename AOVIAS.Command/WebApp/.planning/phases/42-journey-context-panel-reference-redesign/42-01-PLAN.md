# Plan 01 — Journey Context Panel: structure, VM, cards, tokens

## Goal (phase)

Redesign `execution-screen__panel--right` inner experience (`app-journey-context-panel`) to match the **reference Journey Context Panel**: three stacked cards (OE Context, Journey Progress, Quick Actions), token-only styling, chip variants, progress bar + rows, primary/secondary CTAs, quick-action grid, **without** hardcoded colors or fixed pixel widths in component CSS.

## must_haves

- [ ] Three visually distinct **card** regions with **token-based** gap and padding between them.
- [ ] Panel container uses **only** CSS variables for background, border, radius, shadow, spacing.
- [ ] OE header: **“Selected OE:”** muted label + **code** prominent + title/description wrapping.
- [ ] Chips for Department / Role / Frequency with **three** distinct token-backed variants (neutral/blue, purple, green semantics via `color-mix` + existing tokens).
- [ ] Journey Progress card: title, **determinate** progress bar (width from **0–100**), rows for Current Score + status badge, Evidence count, Last updated (formatted).
- [ ] Primary CTA full-width + **secondary** “View History” with outline/ghost; Lucide icons; disabled when `readOnly` lifecycle.
- [ ] Quick Actions: **grid** 3 columns desktop, **2 columns** mobile; hover/active states token-only.
- [ ] Empty state: **“No OE selected”** (or equivalent); loading: **skeleton** placeholders for key blocks.
- [ ] Extend `JourneyContextPanelVm` + store computed for any new fields (`progressPercent`, `loading`, formatted date, `readOnly` flag).
