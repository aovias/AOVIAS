# 30-01: Enhanced Hospital & Framework Selector Dialog

## Objective
Upgrade `HospitalSelectorDialogComponent` to support both hospital AND framework selection in a single modal. Match the design reference with section labels, close button, and dual-radio selection.

## Reference Design
- Title: "Select Hospital & Framework"
- Close (X) icon top-right in header
- "Hospital" section label above hospital radio list
- Hospital items: radio + name (bold) + org (light) + checkmark for selected
- "Framework" section label above framework radio list
- Framework items: radio + name only
- Footer: "Cancel" + "Confirm Selection"
- Confirm disabled until both hospital AND framework are selected

## Tasks

<task id="01" name="Update dialog interfaces">
### Update HospitalSelectorDialogData and return type

**File:** `src/app/shared/ui/hospital-selector/hospital-selector-dialog.component.ts`

Modify the `HospitalSelectorDialogData` interface:
```typescript
export interface HospitalSelectorDialogData {
  hospitals: HospitalSelectorItem[];
  frameworks: FrameworkSelectorItem[];
  selectedHospitalId: string | null;
  selectedFrameworkId: string | null;
}
```

Add new `FrameworkSelectorItem` interface:
```typescript
export interface FrameworkSelectorItem {
  id: string;    // platformId
  name: string;  // framework display name
}
```

Add new `HospitalFrameworkSelection` return interface:
```typescript
export interface HospitalFrameworkSelection {
  hospitalId: string;
  frameworkId: string;
}
```

### Verification
- [ ] `HospitalSelectorDialogData` includes `frameworks` and `selectedFrameworkId`
- [ ] `FrameworkSelectorItem` interface exported
- [ ] `HospitalFrameworkSelection` interface exported
</task>

<task id="02" name="Update dialog template">
### Rewrite dialog template for dual selection

**File:** `src/app/shared/ui/hospital-selector/hospital-selector-dialog.component.ts`

Update the template section:

1. **Header**: Change title to "Select Hospital & Framework". Add close (X) icon button top-right using `flex` layout: title on left, close on right.

2. **Hospital section**: Add `<div class="section-label">Hospital</div>` above the hospital list. Keep hospital items as-is (radio + icon + name + org + checkmark).

3. **Framework section**: Add `<div class="section-label">Framework</div>` followed by a `.framework-list` container. Each framework item:
   - Radio indicator (same style as hospital radio)
   - Framework name (bold)
   - Checkmark if selected
   - Simpler layout than hospital items (no icon, no org sub-text)

4. **Footer**: Keep Cancel + "Confirm Selection" buttons.

5. **Confirm disabled rule**: `[disabled]="!selectedHospitalId() || !selectedFrameworkId() || (selectedHospitalId() === data.selectedHospitalId && selectedFrameworkId() === data.selectedFrameworkId)"`

### Verification
- [ ] Title reads "Select Hospital & Framework"
- [ ] Close (X) icon is top-right
- [ ] "Hospital" section label visible above hospital list
- [ ] "Framework" section label visible above framework list
- [ ] Framework items render with radio + name
- [ ] Confirm button disabled until both selected and at least one changed
</task>

7. Add `onClose()` method — same as cancel, used by X button
