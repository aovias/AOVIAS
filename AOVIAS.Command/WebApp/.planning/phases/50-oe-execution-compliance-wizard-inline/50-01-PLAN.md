## Phase goal (from roadmap)

Deliver an **executable design contract** for the **inline** OE execution wizard: five compliance-focused steps, **Journey Execution–aligned width**, entry from **Resume Journey** / **Start Journey**, token-only styling, **no new business fields**.

- [ ] Structured **wireframe** (regions + breakpoints) stored as `50-DESIGN-WIRE-FRAME.md` in this phase folder.

## Wireframe (summary — full detail in `50-DESIGN-WIRE-FRAME.md`)

### Desktop (≥64rem)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ExecutionScreen header (existing): Back | Journey Execution | Framework ctx │
├─────────────────────────────────────────────────────────────────────────────┤
│ OE Wizard region (inline; same horizontal padding / max-width as workspace) │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │ Row1: [◀ Back]  Breadcrumb: Framework › Chapter › OE   [Status] [Code]   │ │
│ │ Row2: OE Title (h1)                                    [Est. time] [%]   │ │
│ ├─────────────────────────────────────────────────────────────────────────┤ │
│ │ Horizontal stepper: ① Understanding — ② Guidance — ③ Evidence — …     │ │
│ ├─────────────────────────────────────────────────────────────────────────┤ │
│ │ Main: Step card (icon + sections)                     │ Optional rail   │ │
│ │        scrollable                                      │ (guidance)      │ │
│ ├─────────────────────────────────────────────────────────────────────────┤ │
│ │ Sticky footer: [Save draft]     [Previous]  [Next primary]               │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Mobile

- Stepper **vertical** (numbered list, left border accent).
- Footer actions **stack** full width (primary last or per design system).

### Component hierarchy (target)

```
ExecutionScreenComponent
└── .execution-screen (--wizard-open when store.oeWizardOpen())
    ├── … existing workspace (hidden or inert when wizard open — see 50-02)
    └── .execution-screen__oe-wizard-host
        └── OeExecutionWizardComponent
            ├── JourneyWorkspacePrimaryHeader (breadcrumb — add Framework segment vs current 3-seg)
            ├── OeWizardStepperComponent (optional extract) — horizontal / vertical by breakpoint
            ├── OeWizardStepBodyComponent (optional) — `@switch` step index
            └── OeWizardFooterComponent — prev / next / save draft + autosave hint
```

Reuse: `JourneyWorkspacePrimaryHeader`, `NgIcon`, Material buttons; shared **file-upload** pattern from `shared/ui` if already used in journey evidence.
