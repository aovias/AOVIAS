# 32-01: Signup First Name & Last Name — Model, UI Fields, Validation & Payload

## Objective
Add First Name and Last Name fields to the signup Step 3 (Administrator Account), update the `AdminUser` model, validate the inputs, include them in the API request payload, and persist them in sessionStorage. No changes to authentication logic.

## Research Summary

**Current state:**
- `AdminUser` model (`admin-user.model.ts`) only has `email: string` and `password: string`.
- `SignupComponent` (`signup.ts`) Step 3 form (`adminUserForm`) has: `email`, `password`, `confirmPassword`, `agreeToTerms`.
- Template (`signup.html`) Step 3 starts with the Email field at line 330.
- `OnboardingStore` saves/restores `adminUser` to sessionStorage (including only `email` — password is not persisted).
- `OnboardingRequest.adminUser` is typed as `AdminUser` and sent via `POST /onboarding/signup`.
- The form restore on `ngOnInit` patches `{ email: user.email, password: '', confirmPassword: '' }`.
- The `previousStep()` saves `{ email, password }` to store before going back.
- The `onSubmit()` saves `{ email, password }` to store before building payload.

**Approach:** Extend `AdminUser` with `firstName` and `lastName`, add form controls with validation, add side-by-side fields in the template above email, update all save/restore points, and add responsive CSS.

**File:** `src/app/signup/signup.ts`

1. **Add form controls** to `adminUserForm`:
   ```typescript
   adminUserForm: FormGroup = this.fb.group({
     firstName: ['', [Validators.required, Validators.minLength(2), this.noNumericOnlyValidator]],
     lastName: ['', [Validators.required, Validators.minLength(2), this.noNumericOnlyValidator]],
     email: ['', [Validators.required, Validators.email]],

     confirmPassword: ['', Validators.required],
     agreeToTerms: [false, Validators.requiredTrue],
   }, { validators: this.passwordMatchValidator });
   ```

2. **Add custom validator** `noNumericOnlyValidator`:
   ```typescript
   private noNumericOnlyValidator(control: AbstractControl): ValidationErrors | null {
     const value = control.value?.trim();
     if (!value) return null; // Let `required` handle empty
     return /^\d+$/.test(value) ? { numericOnly: true } : null;
   }
   ```

3. **Update `ngOnInit` restore logic** (around line 111-114):
   ```typescript
   const user = this.onboardingStore.adminUser();
   if (user) {
     this.adminUserForm.patchValue({
       firstName: user.firstName || '',
       lastName: user.lastName || '',
       email: user.email,
       password: '',
       confirmPassword: '',
     });
   }
   ```

4. **Update `previousStep()` save logic** (around line 203-208):
   ```typescript

       email: this.adminUserForm.value.email,
       password: this.adminUserForm.value.password,
   ```
