# Phase 60 — Wave 2: Department dropdown + drawer bind + POST create task

## Goal

Replace **free-text department** with **`mat-select`** options loaded from the **department source** decided in research (default: **`CommonLookupService.loadDepartments()`** until hospital-specific endpoint is confirmed). Bind **assignees** from **Wave 1** `OrganizationMembersApiService`. Implement **`ComplianceTaskApiService.createTask(body: CreateComplianceTaskRequest)`** → **`POST /compliance/compliance-tasks`**. Align **`CreateAssignTaskDrawerComponent`** submit handler: build request from store OE/standard IDs + form; map **priority → criticality**; **single assignee** per **`COMPLIANCE_TASK_API_SPEC.md`** (change multi-select to **one** assignee or **primary + warning** — **must** match API). Handle **409** duplicate OE task with user-visible message.

## must_haves

- [ ] **Department:** `mat-select` with `trackBy` id; `FormControl` stores **`departmentId`** (string GUID); display name for `departmentName` on POST; loading/error/empty states.
- [ ] **Assignee:** Populate from Wave 1; value bound to **`assignedToUserId`** (verify field is `userId` from member row per backend).
- [ ] **Linkage IDs:** `objectiveElementId` + `complianceStandardId` from `JourneyWorkspaceStore` / `findOe` / snapshot — **required** before enable Create; show inline error if missing.
- [ ] **Request mapping:** Implement `CreateComplianceTaskRequest` TypeScript interface mirroring spec table; **omit** unsupported draft fields from POST (tags, effort, type, status) or document **local-only** persistence.
- [ ] **Assignee UX:** Resolve **multi vs single** — **recommended:** **single-select** (or keep chips UI but max 1) to match API v1.
- [ ] **Success path:** Close drawer, reset draft, snackbar success; optional **navigate** or **refresh** task list out of scope unless store already exposes hook.
- [ ] **Failure path:** Map envelope errors; **409** shows conflict copy from spec.
- [ ] `ng build` passes; component tests updated for new controls.
