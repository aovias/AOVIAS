# Phase 47 — Plan 02: Shell sidebar overlay vs main content (stacking + interaction)

## Phase goal (backward)

When the **app sidebar** is **open in overlay mode**, **main content** (including Journey Execution) **does not** appear **above** the sidebar; **backdrop** blocks interaction with content **behind**; **focus** remains coherent with existing **cdkTrapFocus** on sidebar.

## must_haves

- [ ] **Z-index / stacking** order: **backdrop** &lt; **sidebar** &lt; **global overlays** (dialogs) — **no** regression of Material dialogs.
- [ ] **Main content** when overlay open: **`pointer-events: none`** or equivalent **scoped** rule so **clicks** do not hit **through** backdrop (verify **touch**).
- [ ] **Execution route** manually tested: open **hamburger** → sidebar covers content; **no** execution panel **visible on top** of sidebar.
- [ ] Token-safe styling; **no** arbitrary hex.
