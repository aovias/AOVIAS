# Phase 47 — Plan 03: Chapter + standards + context — density, hierarchy, feedback, adaptive context

## Phase goal (backward)

**Chapter** rows have **breathing room**, **hover** and **selected** states (token-based). **Standards** and **OE** rows have **clear spacing** and **interaction feedback** (hover/active/focus-visible). **Context** panel: **tablet** = **slide-over** or **collapsible rail**; **mobile** = **bottom sheet** or **expandable** — **UI only**, no new backend.

## must_haves

- [ ] **Chapters:** increased **vertical rhythm**; **active** chapter **left border** or **indicator**; **hover** background/border token.
- [ ] **Standards / OE:** **touch-friendly** minimum vertical spacing between interactive rows; **selected OE** / **chapter** clearly distinct.
- [ ] **Context:** **tablet** breakpoint hides inline right column or shows **toggle**; **mobile** shows **FAB** or **header chip** “Context” opening **sheet** — **no** new data fields.
- [ ] **Buttons** aligned to **action tiers**; **no** floating misaligned controls.
- [ ] **Accessibility:** **focus-visible** on all interactive rows; **ARIA** for **expanded/collapsed** panels.
- [ ] `ng build` passes.
