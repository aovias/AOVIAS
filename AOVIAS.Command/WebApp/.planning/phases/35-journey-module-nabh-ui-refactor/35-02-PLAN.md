# 35-02: Accreditation Bar, Lifecycle Mode & Chapter Navigation Panel

## Objective
Implement the **top accreditation decision panel** (real-time eligibility metrics), **lifecycle mode switch** (Self / Internal / Final / Surveillance), and **enhanced left chapter panel** with search, risk-based sort, core-failure indicators, pending audit badges, and **compliance score** semantics (replacing raw “completion %” copy where specified).

## Tasks

<task id="01" name="AccreditationDecisionPanelComponent">
### Top section: eligibility rules
- Inputs: snapshot metrics from store/service (overall compliance %, core OE average or count, avg standard, avg chapter, violation list).
- Visual: pass/fail rows with ✔/❌; highlight violations; use **existing** semantic colors (danger/warning/success CSS vars).
- **Read-only** display; no backend mutation.

**must_haves:**
- Labels reference **NABH logic** as per spec (thresholds configurable via `const` or `environment` — not hard-coded magic in template).
- Dark/light: use `data-theme` or existing tokens.
</task>

<task id="02" name="LifecycleModeSwitchComponent">
### Toggle: Self | Internal | Final | Surveillance
- Bind to `JourneyWorkspaceStore.lifecycleMode`.
- Document in component: **Final** may filter to Core+Commitment OEs (filter logic in store, applied in 35-03).
- **Edit vs read-only**: expose `readonly` output or store computed — wire placeholder disable on inputs in later waves.

**must_haves:**
- Mode change does **not** reset selected chapter unless current selection invalid (optional guard).
</task>

<task id="03" name="ChapterNavigationPanelComponent">
### Left panel: chapter list
- Show: chapter code + name, **compliance score** (or % per product copy), **risk** (Low/Med/High), **core compliance** summary line, **open issues** count.
- **Search**: filter by name/code.
- **Sort**: toggle risk (desc) vs code order.
- Indicators: **core failure** (badge), **pending audits** (icon/badge).
- Keyboard: focusable items; `aria-current` for selected chapter.

**must_haves:**
- No clause terminology.
- Uses `trackBy` on chapter id.
- Integrates with `filteredChapters()` from store.
</task>

<task id="04" name="Journey shell layout">
### CSS grid: left panel | main scroll
- Responsive: collapse panel to drawer on small breakpoints (Material sidenav or custom — match project patterns).
- Preserve **theme** palette from existing journey styles; refactor duplicated CSS from old monolith into component SCSS/CSS files.

**must_haves:**
- `OnPush` on new components.
- No regression: theme toggle still works.

</task>

## Verification criteria
- [ ] Switching lifecycle updates store signal (unit test or manual).
- [ ] Chapter search + sort work on mock data.
- [ ] Accreditation panel renders with mock metrics without errors.

## must_haves
- **NABH** vocabulary in user-facing strings; **not** “clause”.
- **Compliance score** terminology used for dashboard-aligned metrics where spec requires.
