# Plan 20-01: Onboarding → Hospital Profile → Departments from API (no hardcoded values)

## Objective

Refactor **Onboarding Wizard → Hospital Profile → Departments** to load departments dynamically from backend endpoint `GET /api/v1/common/departments`, replacing all hardcoded lists while preserving current UX (checkbox-card multi-select grid) and adhering to existing Angular architecture (Component → Service → `BaseApiService` → interceptors).

## Scope Notes

- This plan is **only** for the onboarding wizard (AI setup assistant) departments section.
- Existing hardcoded “department” strings in other feature demos (tasks/reporting/control-center) are **out of scope** unless they block compilation or conflict with the new shared lookup service.
- The data contract change is localized to the onboarding wizard model: store and submit **`DepartmentIds: string[]` (GUIDs)**, display uses `Name`, value uses `Id`.
