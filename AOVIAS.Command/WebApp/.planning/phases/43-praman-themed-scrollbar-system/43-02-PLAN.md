# Plan 02 — Global application, scoped usage, browser matrix, verification

## Goal (phase)

Turn the **Phase 43 design specification** into **applied rules**: global application across the app shell, **reusable** scoped patterns for scrollable containers (tables, panels, timelines, lists), **cross-browser** behavior (Chrome, Edge, Safari, Firefox), **responsive** switching (desktop/tablet/mobile), **accessibility** checks, micro-interactions, and **performance** constraints — still using **only** tokens and documented patterns.

## must_haves

- [ ] **Global application** defined for the root document and main app shell scroll surfaces (behavior matches Plan 01; no module-specific exceptions unless using a context variant).
- [ ] **Scoped usage** pattern documented for: OE/task tables, Journey side panels, filter panels, timeline views, evidence/document lists — each references the same variant tokens from Plan 01.
- [ ] **Browser matrix:** WebKit (Chrome/Edge/Safari) styling path + Firefox `scrollbar-width` / `scrollbar-color` path; documented fallback if a platform ignores a property.
- [ ] **Responsive:** Desktop thin scrollbar; tablet slightly wider; mobile/native — **no** custom scrollbar that breaks touch scrolling.
- [ ] **Accessibility:** Focus management and visible focus for keyboard users; contrast expectations for active thumb (per Plan 01 token relationships); no removal of native scrollability.
- [ ] **Micro-interactions:** Subtle fade-in/hover transitions using tokenized motion; no abrupt size jumps.
- [ ] **Performance:** No default dependency on JS scrollbar libraries; native scroll with CSS enhancement only.
- [ ] **Non-blocking UX:** Scrollbar must not overlap critical interactive content; document padding/gutter strategy at design level.
