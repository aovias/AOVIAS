# Domain modelling

This folder is reserved for domain models, glossaries, and context descriptions after product definition supports them.

No domain model is approved. No entities, aggregates, or relationships are defined in this sprint.

## Rules

- Terms must come from canonical Confluence or an approved `REQ` or `DEC`.
- Do not import entities, tables, or names from AOVIAS Command.
- Do not add accreditation standard structure, objective elements, or scoring concepts as if they were an approved domain.
- A glossary entry is not a requirement and not an architecture decision.

When modelling begins, each model document states its status. `Draft` is the starting status. G1 has **not passed**, so this folder stays empty of models until a human assignment names the modelling task and its source.
