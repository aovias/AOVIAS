# Engineering tasks

Engineering task specifications use the identifier series `TASK-NNNN`.

No tasks are open in this folder. Foundation Sprint 0 is recorded in [../FOUNDATION-SPRINT-0-REPORT.md](../FOUNDATION-SPRINT-0-REPORT.md), not as a reusable `TASK` identifier.

## Rules

- Create a specification from [../../../templates/engineering-task.md](../../../templates/engineering-task.md).
- Product implementation tasks cite `Approved` `DEC`, `REQ`, and `ADR` identifiers as applicable, and still require Phase 1 authorization in [../../../GOVERNANCE-STATUS.md](../../../GOVERNANCE-STATUS.md).
- A task that only maintains documentation says so, and does not invent product scope.
- Store specifications in this folder as `TASK-NNNN-short-title.md`.
