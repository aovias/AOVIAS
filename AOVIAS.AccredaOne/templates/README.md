# Templates

Copy a template when a real record is needed. Then:

1. Replace every placeholder.
2. Remove the "Template instructions" section.
3. Keep status as `Draft` unless a human has set a later status.
4. Register the identifier in [../docs/traceability/REGISTER.md](../docs/traceability/REGISTER.md).

A template is not a record. The placeholders are not approved content.
