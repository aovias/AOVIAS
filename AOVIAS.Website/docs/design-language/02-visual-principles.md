# 02 — Visual Principles

**AVLS v1** · Recurring principles extracted from all Creative Direction phases

## Core principles

| Principle | Meaning | Frame evidence |
|-----------|---------|----------------|
| **Void as canvas** | Deep navy/charcoal grounds technical stories | e1, e4, f1, 02 atmosphere board |
| **One accent per viewport** | A single domain/product signal color in view | e3 explicit rule |
| **Platinum structure** | Structural lines in platinum/silver at reduced opacity | e4 illustration rules |
| **Signal, not decoration** | Accent marks activity, focus, or status — not fill | e4, 09 moodboard |
| **Asymmetric heroes** | Text left / visual right with generous negative space | 01, f1, p3 heroes |
| **Horizon as anchor** | Thin platinum horizon line as compositional ground | f1, n10 Horizon Reveal |
| **Isometric lock** | Product/platform illustrations at 30° isometric | e4, 09, d1 |
| **Outline over fill** | Stroke-led illustrations; no gradient fills in line art | e4 |
| **Quiet confirmation** | Feedback without modal noise | n10 Silent Confirmation |
| **Institutional parchment** | Warm editorial surface for company / heritage | e4 Company, 09 moodboard |

## Composition rules

1. **Typography first** — do not use color or motion to replace hierarchy.  
2. **Support, don’t compete** — atmospheres stay behind content (max subtle opacity).  
3. **Grid discipline** — 12-column; intentional 8-pt spacing (Guidelines/06).  
4. **Restrained radius** — 6–16px; no pill-heavy consumer UI.  
5. **Subtle elevation** — shadows explain layering, never dramatize.  
6. **No stock photography** as primary hero art; architectural / institutional photography only when framed (Company parchment exception).  
7. **No generative decorative blobs** as brand identity.

## Lighting philosophy

- Soft volumetric mist / aurora behind technical meshes (enterprise depth)  
- Localized glow on a single node or status light  
- Horizontal light-bars for premium chrome (footer / panels)  
- Avoid neon bloom, multi-color glows, and particle noise  

## Anti-patterns

| Forbidden | Why |
|-----------|-----|
| Multiple competing accent hues in one viewport | Breaks domain clarity |
| Thick illustrative fills / cartoon mascots | Undermines engineering journal tone |
| Loud bounce / elastic motion | Contradicts institutional calm |
| Full-bleed photo heroes with overlay badges | Violates hero budget & brand test |
| Repeating one blueprint grid on every page | Atmosphere monotony (EBAS exists to prevent this) |
