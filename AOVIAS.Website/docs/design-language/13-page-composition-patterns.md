# 13 — Page Composition Patterns

**AVLS v1**

## Canonical page rhythm

```
Hero (EBAS rich + visual)
  ↓
White / canvas content
  ↓
Soft section surface / feature band
  ↓
Domain illustration or diagram band
  ↓
Supporting cards / proof
  ↓
Dark CTA band
  ↓
Enterprise footer
```

## Section surface intents

| Intent | Use |
|--------|-----|
| Canvas | Default reading |
| Muted / feature | Alternating rhythm |
| Blueprint / EBAS subtle | Engineering mid-bands only |
| Contrast / tint | Sparse emphasis |
| Dark CTA | Closing conversion |

## Page family patterns

| Family | Hero | Mid-page | Close |
|--------|------|----------|-------|
| Home | Enterprise + orchestration | Architecture / philosophy bands | Dark CTA |
| Products | Workflow + product pair | Catalog cards | Dark CTA |
| Technology | Platform / mesh | Subject EBAS bands | Dark CTA |
| Industries | Corporate + domain scene | Challenge → solution | Dark CTA |
| Resources | Knowledge | Editorial cards | Dark CTA |
| Company | Corporate / parchment | Mission / culture | Dark CTA |
| Pricing | Minimal | Plan cards | Consultative CTA |
| Contact | Aurora | Form clarity | Minimal chrome |
| Legal | Minimal / none | Long-form prose | Quiet footer |

## Rules

- One job per section  
- One headline + short support  
- Do not stack multiple EBAS-rich bands back-to-back
