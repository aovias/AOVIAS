# 09 — Card Language

**AVLS v1** · Source: `07_card_personality_system`

## Personality model

Cards are **modular tiles** on a calm surface — not loud marketing panels.

| Mode | Content | Treatment |
|------|---------|-----------|
| Brand / identity | Logo / mark field | Dark surface, restrained accent |
| Data / metric | Charts, KPIs | Minimal line chart; no neon |
| Architectural media | Place / institution photo | Soft architectural blur; never selfie stock |
| Documentation | Doc refs, mono labels | Parchment / inverse inset |
| Technical illustration | Isometric module | Outline art + single status glow |

## Rules

1. Consistent square/ratio modules in grids when presenting systems.  
2. Subtle elevation; hairline top accent optional via domain accent.  
3. Generous internal padding.  
4. Category accent via `CardAccent` / `--domain-accent` — not rainbow borders.  
5. Interactive cards: quiet hover lift (existing motion), no scale bounce.  

## Mapping

Existing: `Card`, `FeatureCard`, `ValueCard`, `PrincipleCard`, `PricingCard`, `ArticleCard`, `TrustBadge`.
