# Phase V7 — Knowledge Experience Report

## Mission outcome

AOVIAS Knowledge is an **Enterprise Knowledge Platform**, not a corporate blog. Blog, Insights, Documentation, and Resources share one visual language with distinct purposes.

## Surfaces

| Surface | Route | Purpose | Atmosphere |
|---------|-------|---------|------------|
| Hub | `/resources` | Platform entry + learning path | `knowledge-pattern` |
| Blog | `/resources/blog` | Thought leadership | `aurora` (Editorial Horizon) |
| Insights | `/resources/insights` | Research / executive review | `trust-geometry` |
| Documentation | `/resources/docs` | Structured product docs | `blueprint-grid` |
| Resources | `/resources/library` | Reference library | `knowledge-pattern` |
| Categories | `/resources/categories` | Topic library | `knowledge-pattern` |
| Search | `/resources/search` | Discovery (Release 2-ready) | Static catalog filters |

## Shared rhythm

Hero → Purpose → Category library → Featured → Magazine editorial grid → Learning path → CTA

## Framework

`features/knowledge/editorial/` — `KnowledgeEditorialTemplate`, `EditorialMagazineGrid`, section content modules.
