# 11 — Footer Language

**AVLS v1** · Sources: `08_enterprise_footer_treatment`, `f6_footer_refined`

## Character

Footer **closes the experience** with institutional authority.

## Structure

1. Top light-bar / brand hairline  
2. Optional atmospheric mist / micro-grid at low opacity  
3. Brand summary + mission  
4. Link columns (Products, Technology, Industries, Company, Resources, Legal)  
5. Contact / partner band  
6. Copyright · legal · release/version  

## Surfaces

- Canvas-level dark (`#0A0E14` intent)  
- Light text hierarchy (primary / secondary / tertiary opacities)  
- Social as quiet icon buttons with border  

## Rules

- No bright multi-color social pills  
- No marketing collage  
- Version/release remains visible (trust through continuity)
