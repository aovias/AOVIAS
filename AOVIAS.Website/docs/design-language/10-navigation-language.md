# 10 — Navigation Language

**AVLS v1** · Sources: `n1`–`n9`, Guidelines/06

## Header — default (`n1`)

- Elevated dark bar (Surface 01 / nav tokens)  
- Geometric wordmark left  
- Primary links: Products, Platform/Technology, Solutions, Resources, Company, Pricing  
- Utility: command/search (`⌘K`), theme, sign-in  
- Outline CTA: Contact / Advisory style — ghost border, not loud fill  

## Header — scrolled (`n2`)

- Stronger elevation / hairline  
- Backdrop blur permitted (restrained)  
- Active indicator: thin accent underline or bar  

## Mega menus (`n3`, `n4`)

- Floating elevated panel  
- Top platinum/primary hairline  
- Grouped links with quiet icons  
- Hover: muted primary wash; icon shifts to signal color  

## Command palette (`n5`)

- Keyboard-first search  
- Monospace hints acceptable for shortcuts  
- Dark elevated overlay  

## Interaction states (`n6`)

Align with e2 button matrix for nav CTAs and link hovers.

## Mobile (`n9`)

- Compact chrome  
- Full-screen or drawer menu  
- Preserve CTA accessibility  

## Principles

- Navigation feels like **enterprise application chrome**, not a brochure sticker bar  
- Never hide critical Contact CTA  
- Mega menus explain IA — they are not marketing billboards
