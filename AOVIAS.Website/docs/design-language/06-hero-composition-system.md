# 06 — Hero Composition System

**AVLS v1**

## Universal hero structure

1. Optional breadcrumb (utility pages)  
2. Eyebrow / domain label (accent ink)  
3. Title (typography-led)  
4. One supporting sentence  
5. CTA group (primary + optional secondary)  
6. Dominant visual (illustration / diagram) — typically right column  
7. Named EBAS atmosphere behind  

**Hero budget:** brand signal + one headline + one sentence + CTAs + one dominant visual. No stats strips, promo chips, or floating badges on hero media.

## Composition

- **Asymmetry:** copy left, visual right (desktop)  
- **Quiet right:** atmosphere softens under illustration  
- **Horizon:** optional platinum horizon for enterprise / home signatures  
- **Negative space:** left field remains calm for readability
