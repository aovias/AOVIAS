# 08 — Diagram Language

**AVLS v1** · Sources: phase 2 diagram frames `d1`–`d6`, foundation `06`

## Categories

| Style | Purpose | When to use | Frame refs |
|-------|---------|-------------|------------|
| **Editorial** | Narrative clarity | Company, resources intros | knowledge graph |
| **Isometric** | Spatial systems | Platform ecosystem, infrastructure | d1, 09 racks |
| **Executive** | Board-level simplicity | Homepage, industries overview | simplified hierarchies |
| **Workflow** | Sequential process | Studio, ops loops | d6, workflow atmosphere |
| **Architecture** | Layers & boundaries | Engineering, platform architecture | d2, 06 |
| **Governance** | Controls & oversight | Command, trust, compliance | c1, d5 |
| **Ecosystem** | Multi-node relationships | Technology landing | d1 |
| **Pipeline** | Delivery stages | Deployment / CI narrative | d3 |
| **Deployment** | Runtime path | Cloud / release stories | d3 |

## Shared diagram rules

- Thin consistent strokes  
- Limited node count (readable at hero scale)  
- One accent pathway or active node  
- Labels short; avoid paragraph text inside nodes  
- Dark void or card shell backgrounds — match parent EBAS  
- No comic connectors or emoji  

## Flat vs isometric

| Mode | Use |
|------|-----|
| Flat 2D | Identity flows, AI orchestration boards, docs |
| Isometric 30° | Platform ecosystem, product hardware metaphors |
