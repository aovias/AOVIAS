# R1.8 — Release 1 Deployment Checklist

**Date:** 2026-07-20  
**Status:** Ready

---

## Pre-deploy

- [ ] Node 22 + Docker available
- [ ] `deployment/environments/.env.production` reviewed (no secrets in git)
- [ ] `NEXT_PUBLIC_SITE_URL` set for target host
- [ ] Port free (`HOST_PORT` if needed)
- [ ] CI green on release commit

## Deploy

- [ ] `npm run deploy:local` (or registry pull + compose in target env)
- [ ] Container status `healthy`
- [ ] `npm run deploy:validate`

## Post-deploy

- [ ] Home loads
- [ ] `/robots.txt` and `/sitemap.xml` respond
- [ ] Security headers present (devtools / curl -I)
- [ ] Maintenance page reachable at `/maintenance`
- [ ] Search Console verification env set (if going public)
- [ ] Uptime probe pointed at `/api/health`

## Explicit non-actions

- [ ] Do not enable live analytics (`FF_ANALYTICS` remains false)
- [ ] Do not begin Release 2 automatically
