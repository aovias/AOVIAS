## Workflow

`.github/workflows/ci.yml`

### Jobs

| Job | Stages |
| --- | --- |
| `verify` | Checkout → Install → Lint → Typecheck → Unit placeholder → Build |
| `docker` | Buildx image → Run container → Health wait → Route validation → Artifact |
| `deploy-prepare` | On `main`/`master`: summarize deploy-prep artifact (modular hook for future CD) |

### Future CD (modular)

Add environment-scoped jobs after `deploy-prepare`:

- `deploy-staging` (needs: deploy-prepare, environment: staging)
- `deploy-production` (needs: approval, environment: production)

Do not push images until registry credentials are configured in GitHub Environments.

## Local CI parity

```bash
npm run ci:local
npm run deploy:local
npm run deploy:validate
```
