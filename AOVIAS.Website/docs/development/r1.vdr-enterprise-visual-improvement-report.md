# R1 — Enterprise Visual Improvement Report

**Date:** 2026-07-21
**Status:** Applied, rebuilt, verified on `localhost:3000` (light + dark)

---

## What changed and why

### 1. Dark enterprise CTA band (highest impact)

The closing "Ready to…?" band was the weakest visual moment on every page — a
pale card immediately before the dark footer. `CtaSection` now defaults to a
**dark institutional navy band** (gradient `brand-950 → 900 → 950`) with a
masked blueprint texture, a soft primary glow, a top accent hairline, a
light-filled primary CTA, and an outlined secondary CTA. Every major page now
closes with the same authority the footer carries. Mid-page CTA bands
(product pricing entry, catalog prompts) intentionally stay on light `muted`
surfaces so pages have exactly one dark anchor plus the footer.

### 2. Card personality without icons

`ValueCard` and `PrincipleCard` previously rendered as plain white boxes when
no icon was provided. Both now render a small **domain-accent marker bar**
(or an accent-tinted icon container when an icon exists), so every card grid
carries restrained category identity.

### 3. Statistics that read as statistics

`StatisticCard` values are now set in the **domain accent color** on a subtle
`primary-muted` gradient surface with an accent-tinted border. Numbers like
"Institutions / Long-term / Measured" now attract the eye first.

### 4. Quotes that present as quotes

`QuoteBlock` gained an accent left border, an oversized decorative quote mark,
and lead-size type — the homepage stewardship quote now reads as a considered
statement rather than stray body copy.

### 5. Recognizable trust signals

`TrustBadge` variants now map to semantic identities: security → emerald,
compliance → enterprise blue, quality → indigo, with matching icon tones.

### 6. Visible section rhythm

`--surface-section` (light) deepened from `#f1f4f8` to `#dfe8f2` so soft-blue
bands actually alternate against white instead of disappearing.

### 7. Premium pricing emphasis

Featured plans use the `premium` card accent, a primary ring, floating shadow,
and a **primary-colored price** at heading scale. The recommended plan is now
unambiguous at a glance.

### 8. Confident forms and visible chips

Inputs/textareas/selects gained surface shadows, taller fields (h-10), and
primary hover/focus borders. Badges gained tinted fills with matching borders.

### 9. Section markers

`SectionHeader` eyebrows now carry a short domain-accent rule above the label —
a quiet, recurring brand signature on every section.
