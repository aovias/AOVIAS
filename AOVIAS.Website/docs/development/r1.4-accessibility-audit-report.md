# R1.4 Accessibility Audit Report (WCAG 2.2 AA)

**Date:** 2026-07-20  
**Scope:** Public marketing, product, legal, contact, and auth surfaces  
**Method:** Code audit + keyboard patterns + Lighthouse Accessibility = 100 on critical routes

---

## Verdict

**Pass for Release Candidate entry.** Critical public routes score **A11y 100** under Lighthouse. Shared navigation, forms, and focus foundations meet WCAG 2.2 AA intent for R1.

---

## Foundations verified

| Area | Status |
| --- | --- |
| Skip link → `#main-content` | Pass (`SkipToContent` + focus-visible main) |
| Landmarks (`header` / `main` / footer navs) | Pass |
| Focus visibility (`focus-visible:ring-*`) | Pass on chrome + controls |
| Focus trap (drawer, search, mega-menu) | Pass (`useFocusTrap`) |
| Reduced motion | Pass (motion system respects `prefers-reduced-motion`) |
| Form labels / `aria-required` / errors | Pass (`fieldA11yProps`) |
| Form section naming | Pass (`fieldset` + `legend`) |
| Theme toggle target | Pass (`size-11` / 44px) |
| Search hotkey singleton | Pass (header only; drawer `enableHotkey={false}`) |
| Contact intent tabs | Pass (roving tabindex + arrow keys) |
| Pricing billing radios | Pass (`radiogroup` + arrow keys) |
| External links | Pass (`rel="noopener noreferrer"`) |

---

## Defects closed in R1.4

1. Skip / main focus visibility  
2. Search dual ⌘K / nested drawer dialog  
3. Undersized theme toggle  
4. Missing `aria-required` on required fields  
5. Plan selector / billing incorrect tab ARIA → radiogroup patterns  
6. Logo / control hit areas on mega-menu chevrons  
7. Checkbox / radio / switch sizing toward 24px minimum  

---

## Residual / RC follow-ups (non-blocking)

- Optional APG menubar Left/Right across top-level mega-menu items  
- Background `inert` when modals open (enhancement beyond current trap)  
- Full Safari VoiceOver pass on macOS/iOS (environment-limited on Windows)
