# Enterprise Background & Atmosphere System (EBAS) — Architecture

**Release:** 1  
**Sprint:** EBAS  
**Status:** Implemented and verified on production build (`localhost:3000`)

## Purpose

Replace repetitive procedural blueprint grids with a reusable registry of named atmosphere assets. Pages declare a background type; they do not embed custom decorative CSS.

## Principles

1. **Support content** — atmospheres never compete with typography or illustrations.
2. **Named assets** — every background is a registry key with label + intent.
3. **Semantic tokens only** — surfaces, borders, `--domain-accent`, `--brand-atmosphere`, `--color-accent`.
4. **Theme-aware** — light/dark resolve through CSS variables automatically.
5. **Responsive** — density scales and masks adapt; marks hide below `lg`/`sm` breakpoints.
6. **Domain tint** — route-level `data-product` / `data-technology` / `data-industry` recolor accents without page-level hardcodes.

## Architecture

```
Hero / ProductHero / SectionSurface / layouts
        │
        ▼
BrandAtmosphere (compat façade)
        │
        ▼
EnterpriseAtmosphere (renderer)
        │
        ▼
enterpriseAtmosphereRegistry[variant]
  · base gradient
  · pattern (+ size / mask / opacity)
  · optional detail layer
  · optional silhouette mark (frame | diamond | rings | nodes | lanes)
```

### Key files

| File | Role |
|------|------|
| `apps/website/src/components/brand/enterprise-atmosphere.tsx` | Registry + renderer |
| `apps/website/src/components/brand/brand-atmosphere.tsx` | Compatibility entry (`variant` default = `blueprint-grid`) |
| `apps/website/src/components/marketing/hero.tsx` | `atmosphere?: boolean \| EnterpriseAtmosphereVariant` |
| `apps/website/src/components/product/product-hero.tsx` | Same API for product detail heroes |
| `apps/website/src/components/marketing/section-surface.tsx` | Optional mid-page `atmosphere` |
| `apps/website/src/components/marketing/home-hero-atmosphere.tsx` | Home: `enterprise-abstract` |

### API

```tsx
<Hero atmosphere="ai-neural-network" … />
<BrandAtmosphere variant="security-geometry" density="rich" quietRight />
<SectionSurface atmosphere="architecture" tone="feature" … />
```

Density: `subtle` (0.62) · `default` (0.85) · `rich` (1.0)

### Composition layers

1. Base multi-stop gradient (hero → background → muted)
2. Pattern plane (CSS gradients / dots / lanes / mesh)
3. Detail plane (secondary node field when defined)
4. Domain-accent glow orb
5. Variant silhouette marks
6. Institutional corner marks (shared chrome)

## Quality gates met

- Pages declare named atmospheres instead of one shared grid
- Blueprint reserved for engineering contexts
- AI / Security / Products / Company / Resources / Legal each reinforce subject
- Typography remains primary; opacities stay restrained
- Existing design system and routing preserved
