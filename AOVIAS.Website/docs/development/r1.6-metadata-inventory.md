# R1.6 — Metadata Inventory

**Date:** 2026-07-20  
**Status:** Complete

---

## Generation model

Every public page uses `createPageMetadata({ title, description, path, type, keywords?, image?, … })`.

Inherited automatically:

- Canonical URL
- Open Graph (title, description, url, image, siteName, locale, type)
- Twitter Card (`summary_large_image`)
- Robots (env-aware)
- Icons / theme-color

## Section coverage

| Section | Routes | Title/Description | Canonical | OG image |
| --- | --- | --- | --- | --- |
| Home | `/` | Feature `homeSeo` | Yes | `/og/home.png` |
| Company | `/company`, careers, contact | Feature SEO modules | Yes | company / careers / contact |
| Products | `/products`, `/products/[slug]` | Feature + detail SEO | Yes | products / command / studio / default |
| Pricing | `/pricing` | `pricingSeo` | Yes | `/og/pricing.png` |
| Technology | Hub + nested (T1–T6) | Feature SEO per route | Yes | `/og/technology.png` |
| Solutions | `/solutions`, `/solutions/[slug]` | Industry SEO | Yes | `/og/solutions.png` |
| Resources | Hub, kinds, categories, search, detail | Knowledge SEO | Yes | resources / blog / documentation |
| Legal | Hub + policies | Legal SEO helpers | Yes | default (legal) |
| Auth / Checkout | Identity + commerce flows | Present, **noindex** via robots disallow | N/A for indexing | — |

## Non-indexed surfaces

- `/dev/**`, `/internal/**`, `/*/preview`, `/auth/**`, `/checkout/**`, `/api/**`, `/admin/**`, `/console/**`

## Gaps closed in R1.6

- Technology pages no longer share generic default OG without a section asset
- Solutions hub has explicit OG image
- Home uses dedicated `/og/home.png`
- Verification env placeholders wired into root metadata

## Maintenance

Add new public routes to `seoConfig.sitemap.routes` and call `createPageMetadata` on the page. Prefer `ogImages` from `@/seo` over string literals.
