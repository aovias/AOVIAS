# R1.VA.2 — Brand Color Distribution Report

**Date:** 2026-07-21
**Milestone:** M5 (Color distribution) + M7 (Domain identity)
**Status:** Complete

---

## Target distribution

| Share | Role |
| --- | --- |
| ~65% | Neutral enterprise surfaces |
| ~20% | Primary blue |
| ~10% | Domain accents |
| ~5% | Interactive highlights |

Color is used to **guide attention**, not decorate.

## How the distribution is achieved

### Neutral base (~65%)

- Page and section backgrounds stay on neutral/surface tokens.
- Cards use near-neutral gradients; text uses `ink` / `ink-muted`.

### Primary blue (~20%)

- Header wash + scroll hairline, dark footer, hero atmosphere, CTA bands,
  primary buttons, and section eyebrows all lean on the primary family.
- Brand hues were re-saturated so primary reads as a clear blue instead of a
  near-charcoal neutral (`--primary` → `primary-600` light / `primary-300` dark).

### Domain accents (~10%)

- Applied only to icons, badges, section markers, illustrations, card top bars,
  and diagrams via `--domain-accent` — never as page tints.
- Product/Technology accent hexes increased in saturation
  (`colors.ts` / `tokens.css`) so indigo, cyan, and emerald are discernible.

### Interactive highlights (~5%)

- Hover states, focus rings, active nav indicator, and CTA emphasis.

## Token changes summary

- `themes.css` — brighter `--primary`, `--secondary`, `--accent`, `--supporting`,
  new `--illustration-ink`, and category `[data-accent]` wiring.
- `tailwind-theme.css` — `--color-illustration-ink` alias.
- `colors.ts` / `tokens.css` — saturated product/technology accent hexes.

## Guardrails

- All values remain within the semantic token system; contrast preserved for AA.

## Validation

- Computed styles inspected via devtools; primary and domain accents now resolve
  to clearly chromatic values in both themes.
