# R1.6 — XML Sitemap Report

**Date:** 2026-07-20  
**Status:** Complete

---

## Endpoint

`/sitemap.xml` → `app/sitemap.ts` → `buildSitemapEntries`

## Sources

1. **Static registry:** `seoConfig.sitemap.routes` (home, company, products, pricing, technology tree, solutions, resources hubs, legal)
2. **Knowledge detail:** `knowledgeCatalog` items
3. **Knowledge categories:** `/resources/categories/{slug}`
4. **Planned industries:** industry catalog `status === 'planned'`

## Environment behavior

| Environment | Sitemap |
| --- | --- |
| production (`NEXT_PUBLIC_APP_ENV=production`) | Full URL set |
| development / preview / test | Empty (not indexable) |

## Coverage classes

- Static marketing pages
- Product pages (available + vision)
- Technology pages (platform, AI, engineering, trust, ecosystem)
- Resource hubs + articles
- Legal pages
- Future-ready: append via `createSitemapRoute` without changing the builder

## Exclusions (intentional)

Preview shells, `/dev`, `/internal`, auth, checkout, API, admin/console.

## Gate

Build emits `/sitemap.xml` route. Smoke script confirms sitemap module presence.
