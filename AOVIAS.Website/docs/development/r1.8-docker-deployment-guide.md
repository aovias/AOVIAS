# R1.8 — Docker Deployment Guide

**Date:** 2026-07-20  
**Status:** Complete

---

## Prerequisites

- Docker Desktop / Engine 24+
- Node 22+ (for local validate scripts)
- Ports: `3000` free (or set `HOST_PORT`)

## One-command production (recommended)

From repository root:

```bash
npm run deploy:local
```

This builds `aovias-website:r1` (target `runner`) and starts `deployment/compose/docker-compose.prod.yml`, then probes `/api/health`.

## Manual commands

```bash
# Build
npm run docker:build

# Start
npm run docker:up

# Validate
npm run deploy:validate

# Stop
npm run docker:down
```

## docker run

```bash
docker run --rm -p 3000:3000 \
  -e NODE_ENV=production \
  -e NEXT_PUBLIC_SITE_URL=http://localhost:3000 \
  -e NEXT_PUBLIC_APP_ENV=production \
  aovias-website:r1
```

## Image design

| Stage | Purpose |
| --- | --- |
| `deps` | `npm ci` from package manifests |
| `builder` | `next build` → standalone |
| `runner` | Minimal Alpine, non-root, HEALTHCHECK |
| `development` | Compose hot-reload target |

## Optional nginx

```bash
docker compose -f deployment/compose/docker-compose.prod.yml --profile proxy up -d
```

Proxy listens on `PROXY_PORT` (default 8080).
