# R1.7 — Event Taxonomy Guide

**Date:** 2026-07-20  
**Status:** Complete

---

## Convention

```
{namespace}.{verb}
{namespace}.{object}.{verb}
```

Namespaces (`EVENT_NAMESPACES`):

`navigation` · `page` · `product` · `technology` · `pricing` · `contact` · `career` · `search` · `resource` · `conversion` · `identity` · `commerce` · `error`

## Rules

1. **Lowercase + snake_case segments** after the namespace (`item_selected`, not `itemSelected`).
2. **No provider names** in event names (`page.viewed`, never `ga.page_view`).
3. **Version in registry**, not in the name (`page.viewed` v1 → v2 via `version` field).
4. **Conversions** use `conversion.*` for funnel reporting; domain events may mirror (`contact.demo_requested`).
5. **Attributes** use dotted keys: `page.path`, `product.slug`, `cta.id`, `nav.menu`.

## Anti-patterns

- Mixing `PageViewed` / `page_view` / `pageView`
- Embedding PII in attribute values
- Creating one-off names outside the registry
- Calling providers with raw GA/PostHog event strings from UI

## Helper

`assertEventNameConvention(name)` validates namespace membership.
