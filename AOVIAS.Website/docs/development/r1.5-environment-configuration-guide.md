# R1.5 — Environment Configuration Guide

**Date:** 2026-07-20

---

## Profiles

Documented in `src/environments/index.ts`: development · preview · production · release2 (future).

## Core env (`config/env.ts`)

| Variable | Role |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical site origin |
| `NEXT_PUBLIC_APP_ENV` | development / staging / production |

## Integration placeholders (unused by mocks)

| Variable | Service |
| --- | --- |
| `NEXT_PUBLIC_IDENTITY_API_URL` | Identity |
| `NEXT_PUBLIC_COMMERCE_API_URL` | Commerce |
| `NEXT_PUBLIC_CONTACT_API_URL` | Contact |
| `NEXT_PUBLIC_KNOWLEDGE_API_URL` | Knowledge |
| `NEXT_PUBLIC_SEARCH_API_URL` | Search |
| `NEXT_PUBLIC_ANALYTICS_API_URL` | Analytics |

## Feature flags

| Flag | Default |
| --- | --- |
| `NEXT_PUBLIC_FF_USE_MOCK_SDKS` | true |
| `NEXT_PUBLIC_FF_*_LIVE` | false |
| `NEXT_PUBLIC_FF_ANALYTICS` | false (true if production app env) |

See `.env.example` for the full template.
