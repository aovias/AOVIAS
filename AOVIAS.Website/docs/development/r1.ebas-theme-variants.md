# EBAS — Theme Variants (Light / Dark)

## Strategy

EBAS does **not** maintain duplicate light/dark registries. Each atmosphere is defined once using semantic CSS variables. Themes remap those variables in `packages/design-system/src/css/themes.css`.

## Token dependencies

| Token | Role in atmospheres |
|-------|---------------------|
| `--surface-hero` | Hero canvas start |
| `--background` | Mid-field wash |
| `--surface-muted` | Depth edge |
| `--brand-atmosphere` | Soft brand wash orb |
| `--domain-accent` | Pattern ink + glow (route-scoped) |
| `--color-accent` | Secondary intelligence tint (AI / aurora) |
| `--color-border` | Structure lines |

## Light theme

- Cool blue-tinted canvases (`--surface-hero` ≈ `#d7e5f6`)
- Patterns read as soft structure against pale surfaces
- Domain accent provides category identity without page tinting

## Dark theme

- Navy charcoal canvases (`--background` ≈ `#090d15`)
- Same pattern geometry; higher relative contrast on `--domain-accent` / primary-300 steps
- Glow orbs remain subtle — no neon bloom

## Responsive behaviour

- Pattern `background-size` uses `clamp()` for large-screen immersion
- `max-sm:scale-110` slightly enlarges patterns on small screens (less visual noise density)
- Geometric marks (`diamond`, `rings`, `nodes`, `frame`) show from `lg` upward
- Corner marks from `sm` / `lg`
- `quietRight` fades pattern under right-column illustrations so diagrams stay readable
