# R1.VA — Color System Refinement Report

**Date:** 2026-07-20  
**Status:** Complete — calm enterprise palette deepened, not exploded

---

## Changes

### Theme surfaces (`themes.css`)

- Canvas shifted to cool-neutral `#f4f5f7` (was warmer cream)
- `--muted` / `--subtle` given blue-tinted institutional bands
- Shadow ladder strengthened slightly with primary-ink bias

### Layout widths (`tokens.css` + `layout.ts`)

- Content max: **1440px** (was 1360)
- Hero max: **1760px** (was 1600)

### Section surface system

New `SectionSurface` tones:

| Tone | Use |
| --- | --- |
| `canvas` | Default reading band |
| `muted` | Soft institutional band |
| `subtle` | Cooler secondary band |
| `tint` | Brand-blue wash (~3.5% primary) |
| `blueprint` | Grid texture + muted |
| `contrast` | Stronger primary tint for trust/emphasis |

---

## Principles preserved

- No startup neon / purple explosions  
- Accent remains restrained enterprise blue  
- Cards stay white/elevated against tinted bands  
- Dark theme semantics unchanged in structure  

---

## Card elevation

Feature cards default to `elevated` when non-linked; interactive cards retain hover surface behavior with existing shadow tokens.
