# R1.VA.2 — Surface & Section Rhythm Report

**Date:** 2026-07-21
**Milestone:** M3 (Section surfaces) + M6 (Hero atmosphere)
**Status:** Complete

---

## Goal

Give the page a composed vertical rhythm so each section feels distinct while the
overall page stays calm.

## Surface system (`components/marketing/section-surface.tsx`)

`SectionSurface` tones provide the alternation pattern:

| Tone | Role |
| --- | --- |
| `hero` / default white | Opening + breathing room |
| `section` (soft blue) | Primary supporting band |
| `muted` | Quiet contrast band |
| `feature` | Gradient highlight band (`surface-section → card → surface-muted`) |
| `blueprint` | Institutional texture band with radial depth |
| `elevated` | Raised, bordered emphasis |

A representative flow (home / marketing):

```
Hero → feature → white → blueprint → muted → enterprise highlight → dark CTA → footer
```

Company, Products, and Technology surfaces were mapped onto these tones so no two
adjacent sections read the same.

## Hero atmosphere (M6)

- `BrandAtmosphere` gained a `density` control; heroes now request `density="rich"`
  for layered blueprint grids, engineering line patterns, radial lighting, and
  institutional corner marks.
- `Hero` and `ProductHero` frame their illustrations with a soft domain-accent
  glow (`bg-domain-accent/10` blur) and larger min-heights on wide screens so big
  displays feel immersive rather than stretched.
- `BrandShell` renders illustrations inside an elevated gradient frame with a
  domain-accent top hairline.

## Guardrails

- Section order, spacing scale, and container widths unchanged.
- Tones are additive props; existing sections keep their semantics.

## Validation

- Reviewed home, products, technology, and company pages on `localhost:3000` in
  both themes — clear, calm alternation confirmed.
