## Endpoint

`/robots.txt` → `app/robots.ts` → `buildRobotsConfig`

## Production rules

- **Allow:** `/` (public website)
- **Disallow:**
  - `/dev/`, `/api/`, `/auth/`, `/checkout/`, `/internal/`
  - `/*/preview`, `/*/preview/`
  - `/admin/`, `/console/` (future)
- **Sitemap:** `{origin}/sitemap.xml`
- **Host:** site origin from `getSiteUrl()`

## Non-production

`Disallow: /` for all user agents. Sitemap URL still declared for tooling consistency; sitemap body is empty when not production.

## Config source

## Gate
