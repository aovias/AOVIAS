## Deploy


## Health

```bash
curl -fsS http://localhost:3000/api/health
curl -fsS http://localhost:3000/api/ready
docker compose -f deployment/compose/docker-compose.prod.yml ps
```

## Logs

```bash
docker compose -f deployment/compose/docker-compose.prod.yml logs -f website
```

## Maintenance mode

1. Set `MAINTENANCE_MODE=true` in env / compose
2. Recreate container
3. Public routes rewrite to `/maintenance`; `/api/health` stays up

## Rollback

1. `docker compose -f deployment/compose/docker-compose.prod.yml down`
2. Redeploy previous image tag (CI artifact / registry digest)
3. Or rebuild known-good git SHA: `git checkout <sha> && npm run deploy:local`

## Common failures

| Symptom | Check |
| --- | --- |
| Port bind error | Free port 3000 or set `HOST_PORT` |
| Unhealthy | `docker logs`, `/api/health` |
| Blank assets | Confirm `.next/static` copied in image |
| Wrong canonical | `NEXT_PUBLIC_SITE_URL` |
