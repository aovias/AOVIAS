# AOVIAS Color Usage Guide

Brand color usage maps to the **existing design-system tokens**. This guide does not redefine the UI palette.

## Roles

| Role | Guidance |
| --- | --- |
| Ink / foreground | `foreground` / `primary` for marks and strokes |
| Surface | `background`, `card`, `muted` |
| Accent (star) | Cyan → royal blue gradient on the mark star only; keep restrained |
| Borders | `border` at low emphasis |

## Rules

- Prefer calm neutrals for large fields  
- Avoid loud multi-stop marketing gradients on backgrounds  
- Light/dark compatibility: use `currentColor` SVGs or paired light/dark exports  
- Accent blue is for navigation/precision in the mark — not rainbow decoration  

## Asset export colors (file masters)

| Token name | Approx hex (export) | Use |
| --- | --- | --- |
| Ink dark | `#0B1220` | Light-theme logos |
| Ink light | `#F4F7FB` | Dark-theme logos |
| Navy deep | `#081020` | Dark OG / app icon fields |
| Star center | `#5EC8FF` | Mark accent |
| Star tip | `#1E4FD8` | Mark accent |
