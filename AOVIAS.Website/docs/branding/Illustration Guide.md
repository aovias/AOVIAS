# AOVIAS Illustration Guide

## Principle

**Illustrations explain; they never decorate.**

Every illustration answers: what is AOVIAS trying to explain?

## Family

Shared stroke, radius, opacity ladder, and grid module — see Brand Identity Guide and `docs/design-system/brand-illustrations.md`.

## File library

Static exports live in `assets/brand/illustrations/` (SVG, light/dark where needed). React sources remain in `apps/website/src/components/brand/` for the live site.

## Domains

Platform · Operations · Healthcare · Government · Education · Enterprise · AI · Security · Trust · Monitoring · Deployment · Architecture · Workflow · Institution · People

## Review

Reject cartoon characters, loud gradients, and trend stickers. Prefer blueprint geometry.
