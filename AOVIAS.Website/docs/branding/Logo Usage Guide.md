# AOVIAS Logo Usage Guide

## Lockups

| Lockup | Use |
| --- | --- |
| Primary / Horizontal | Headers, documents, most marketing |
| Vertical | Square placements, covers, app splash |
| Icon only | Favicons, app icons, compact chrome |
| Wordmark only | When mark already appears nearby |

## Clear space

Minimum clear space = height of the mark’s inner triangle on all sides. Do not crowd with other logos or dense UI.

## Minimum sizes

| Format | Minimum |
| --- | --- |
| Horizontal digital | 120 px wide |
| Icon only | 16 px |
| Print horizontal | 25 mm wide |

## Themes

| Variant | Background |
| --- | --- |
| Light theme | Light / white surfaces — dark ink + blue star |
| Dark theme | Dark navy / black — light ink + blue star |
| Monochrome | Single ink (black or white) — no star gradient if contrast fails |

## Do

- Use SVG masters from `assets/brand/_masters/` when possible  
- Preserve aspect ratio  
- Prefer transparent backgrounds  

## Don’t

- Stretch, rotate arbitrarily, or add drop shadows / glow for “impact”  
- Place dark lockup on dark backgrounds (or light on light)  
- Recolor the star to brand-incompatible hues  
- Combine with competing geometric marks  

## File locations

- Masters: `assets/brand/_masters/logos/`  
- Exports: `assets/brand/logos/`  
- Website runtime: `apps/website/public/brand/`
