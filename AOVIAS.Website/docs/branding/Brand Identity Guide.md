# AOVIAS Brand Identity Guide

**Status:** Canonical Brand Design System (separate from UI Design System)  
**Scope:** All AOVIAS touchpoints — website, products, docs, decks, social, email

---

## Purpose

This guide defines the visual identity of AOVIAS so every asset feels like one family for years.

AOVIAS communicates: **trust, engineering, precision, institutional quality, long-term thinking, professionalism.**

---

## Personality

| We are | We are not |
| --- | --- |
| Calm | Loud |
| Precise | Trend-chasing |
| Geometric | Cartoonish |
| Institutional | Startup-spectacle |
| Blueprint / architectural | Decorative collage |

---

## Visual pillars

1. **Geometry** — frames, nodes, connectors, open-A motifs  
2. **Structure** — grid modules, clear hierarchy  
3. **Technical precision** — consistent stroke weights and radii  
4. **Calm palette** — mapped to design-system tokens; restrained accent blue for the mark star  
5. **Explanation first** — illustrations and diagrams teach; they never decorate  

---

## Family contract (illustration & diagram)

| Token | Value |
| --- | --- |
| Stroke | 1 / 1.25 / 1.5 / 2 |
| Radius | 6 / 8 |
| Fill opacity | 0.05 → 0.14 (accent ~0.18) |
| Grid step | 20–28 |

See also: `docs/design-system/brand-illustrations.md` and `assets/brand/`.

---

## Brand review loop

Before approving any asset:

1. Does this look like AOVIAS?  
2. Would this still look modern in ten years?  
3. Can it be reused across every product?  
4. Does it communicate trust?  
5. Does it reinforce engineering excellence?  

If not — iterate.
