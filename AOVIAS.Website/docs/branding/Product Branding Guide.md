# AOVIAS Product Branding Guide

## Family rule

All products share the AOVIAS mark language. Each remains individually recognizable via a secondary motif and wordmark.

| Product | Motif | Job |
| --- | --- | --- |
| AOVIAS | Open-A + star | Platform / company |
| Command | Control node / ops crosshair | Operations workspace |
| Studio | Delivery frame / panel | Delivery workspace |
| Sentinel | Vigilance arc | Assurance (vision) |
| Nexus | Linked nodes | Interoperability (vision) |
| Insight | Focus diamond | Measured intelligence (vision) |
| Flow | Path continuum | Workflow continuity (vision) |

## Lockups

`assets/brand/logos/products/` — horizontal SVG + PNG for each product.

## Do not

- Swap Command and Studio motifs  
- Use vision product logos to imply commercial availability in customer-facing claims
