# R1.DS.3 — Elevation System Report

**Date:** 2026-07-21

## Levels

| Level | Token | Use |
| --- | --- | --- |
| Flat | `shadow-flat` | Flush surfaces |
| Surface | `shadow-surface` | Cards, buttons (default) |
| Raised | `shadow-raised` | Featured cards, sticky chrome |
| Floating | `shadow-floating` | Menus, search dialog, popovers |
| Overlay / Modal | `shadow-overlay` / `shadow-modal` | Overlays, modals |

Theme maps in `themes.css` keep hairline + soft lift (calibrated in R1.DS.2.1).

## Radius

Standard tokens only: `none` | `sm` | `md` | `lg` | `xl` | `full`.

| Element | Radius |
| --- | --- |
| Buttons / inputs / badges | `md` (sm for dense chips/kbd) |
| Cards / mega / search | `lg` |
| CTA bands / large panels | `xl` |
