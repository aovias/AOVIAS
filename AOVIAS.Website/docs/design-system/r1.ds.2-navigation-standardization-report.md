# R1.DS.2 — Navigation Standardization Report

**Date:** 2026-07-21

## Token roles

| Role | CSS | Usage |
| --- | --- | --- |
| Nav default | `--nav-foreground` | Main nav, mega triggers |
| Nav hover | `--nav-foreground-hover` | Links / triggers |
| Nav active | `--nav-foreground-active` | Current primary item |
| Nav chrome | `--nav-background` | Sticky header |
| Mega panel | `--nav-mega-background` | Mega menu surface |
| Footer links | `--nav-footer-foreground` | Footer link ink |
| Breadcrumb | `--breadcrumb-foreground` | Ancestors |
| Breadcrumb current | `--breadcrumb-current` | Current page |
| Focus | `--focus-ring` | Keyboard focus |

## Components updated

- `HeaderChrome` → `bg-nav-background`
- `MainNav` → nav foreground / active roles
- `MegaMenuPanel` → `bg-nav-mega-background` + nav hover
- `Breadcrumbs` → breadcrumb roles + `ring-focus-ring`
- `SiteFooter` link styles → footer nav role

Spacing/alignment retain existing stack/gap tokens; no layout redesign.
