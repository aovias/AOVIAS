# R1.DS.2 — Typography Standardization Report

**Date:** 2026-07-21

## Semantic type roles

| Role | Token / utility | Scale |
| --- | --- | --- |
| Display | `text-display` / `display-l` | 3.75rem |
| Hero Title | `text-hero-title` | 3rem (= page title) |
| Page Title | `text-page-title` | 3rem |
| Section Title | `text-section-title` | 2.5rem |
| Card Title | `text-card-title` | 1.5rem |
| Subheading | `text-subheading` | 1.25rem |
| Lead | `text-lead` | 1.125rem |
| Body | `text-body` | 1rem |
| Caption | `text-caption` | 0.75rem |
| Muted | `text-ink-muted` / `text-muted-foreground` | color role |
| Link | `text-accent` / Button `link` | color role |

## Page title unification

| Surface | Before | After |
| --- | --- | --- |
| Marketing `Hero` | `display-l` default | `hero-title` |
| `ProductHero` | `display-l` | `hero-title` |
| `PageHeader` | `text-h3` | `text-page-title` |
| `Heading` level 1 default | `h1` | `page-title` |

All page titles now share the same size role (`3rem` / `font-size-page-title`).

## Implementation

- TS: `packages/design-system/src/tokens/typography.ts`
- CSS: `--font-size-*` in `tokens.css` + `@theme` aliases in `tailwind-theme.css`
- UI: `Heading` size map includes role aliases
