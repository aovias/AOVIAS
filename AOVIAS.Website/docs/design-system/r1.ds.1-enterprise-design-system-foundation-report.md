**Status:** Complete — **ready for R1.DS.2 Semantic Color Token System**

## Executive summary

AOVIAS website UI has been inventoried across layouts, primitives, marketing, navigation, brand visuals, products, forms, pricing, resources, trust, system states, and motion. All visible reusable surfaces map into a 16+ family taxonomy with a full registry, hierarchy trees, recipes, and a token **role** dependency matrix.

This sprint produced **documentation only**. No UI changes, refactors, renames, or token **values** were introduced. Existing API guides under `docs/design-system/` remain the props reference; R1.DS.1 docs are the classification source of truth.
