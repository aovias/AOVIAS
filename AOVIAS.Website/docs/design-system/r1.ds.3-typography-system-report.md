| Caption | `text-caption` | |

| Link | `text-accent` | Interactive |

## Fluid titles

`--font-size-hero-title` / `page-title` / `section-title` / `display*` use `clamp()` for responsive consistency without arbitrary per-breakpoint classes.

## Consumers

`Heading`, `Text` (eyebrow/label/helper), `Paragraph`, `Quote`, heroes, section headers, page headers, cards.
