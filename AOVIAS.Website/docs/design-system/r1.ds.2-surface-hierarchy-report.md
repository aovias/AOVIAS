# R1.DS.2 — Surface Hierarchy Report

**Date:** 2026-07-21

## Hierarchy (light)

1. **Canvas** — `--background` (page)
2. **Hero** — `--surface-hero` + Brand Atmosphere
3. **Section bands** — `--surface-muted` / `--surface-subtle` / `--surface-section` via `SectionSurface` tones
4. **Elevated cards** — `--surface-elevated` / `--card` + `shadow-surface|raised`
5. **Chrome** — `--nav-background` (translucent over canvas)

## SectionSurface tone → token

| Tone | Token utility |
| --- | --- |
| canvas | `bg-background` |
| muted | `bg-surface-muted` |
| subtle | `bg-surface-subtle` |
| tint | `bg-primary-muted/40` |
| blueprint | `bg-surface-section` + border grid |
| contrast | `bg-primary-muted/60` |

## Atmosphere

`BrandAtmosphere` uses `from-surface-hero`, `bg-brand-atmosphere`, `bg-divider` — soft gradients + blueprint grid without visual noise.

## Intent

Alternating bands + elevated cards eliminate flat single-canvas appearance while remaining calm and institutional.
