# R1.DS.3 — Layout Rhythm Report

**Date:** 2026-07-21

## Vertical rhythm

| Band | Token |
| --- | --- |
| Hero | `py-hero-y` (fluid) |
| Section default | `py-section-y-lg` via SectionSurface |
| Compact section | `py-section-y-md` |
| Expansive / system | `py-section-y-xl` |

## Horizontal / grid

| Role | Token |
| --- | --- |
| Content / hero max | `layout.content-max` / `hero-max` (1440 / 1760) |
| Hero + product grids | `gap-grid-gap` / `gap-grid-gap-lg` |
| Stacks | `gap-stack-*` / Stack gap props |

## Density

- Controls: `h-8`/`h-9`/`h-11` with `px-control` equivalents (`px-3`)
- Cards: `p-card` (24px)
- Nav: compact `text-small` + indicator underline
- Comfortable reading width: Container narrow/default/wide unchanged
