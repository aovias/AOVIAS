## Hot paths for R1.DS.2 (color first)

Prioritize assigning **color roles → values** for:

1. `color.surface` / `color.surface-elevated` / `color.surface-muted`
2. `color.ink` / `color.ink-muted` / `color.ink-inverse`
3. `color.border` / `color.border-strong`
4. `color.accent` / `color.accent-muted`
5. `color.focus-ring`
6. Status: `color.danger|success|warning|info`
7. `color.brand-atmosphere` / `color.overlay`

These unlock Header, Section Surface, Button, Card, Hero, and Form control theming without touching type/space scales yet.
