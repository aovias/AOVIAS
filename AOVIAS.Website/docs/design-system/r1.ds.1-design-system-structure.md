## Relationship to existing API docs

API docs under `docs/design-system/*-components.md` describe **props and usage**. This structure document describes **where they belong** in the enterprise DS. Prefer taxonomy names in new work; keep code names in registry mappings.

---

## Evolution rules

1. New visible UI must declare a taxonomy family before merge.
2. New token families require Foundations update here before value assignment.
3. Do not create parallel color systems outside `packages/design-system` after R1.DS.2.
