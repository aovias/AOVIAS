## Active & hover

| State | Token / class | Notes |
| --- | --- | --- |
| Default nav | `--nav-foreground` | Neutral, secondary to content |
| Hover | `--nav-foreground-hover` | Subtle shift toward primary |
| Active | `--nav-foreground-active` + underline `--nav-indicator` | Immediately obvious; primary blue (not cyan) |
| Breadcrumb current | `--breadcrumb-current` | Primary; trail uses `--breadcrumb-foreground` |
| Footer links | `--nav-footer-foreground` | Calm; hover lifts slightly |

---

## Visual findings (production)

- **Technology** and **Products** active underlines read clearly in light and dark.
- Breadcrumbs on product/technology pages are secondary and do not compete with page titles.
- Footer remains a quiet close to the page — no high-chroma accents.

---

## Changes this sprint

- `--nav-indicator` → primary scale (light + dark).
- Breadcrumb list size → `text-caption` for secondary hierarchy.
- Link tones aligned to primary for consistency with nav interactive language.
