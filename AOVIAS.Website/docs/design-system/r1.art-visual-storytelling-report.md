# R1.ART — Visual Storytelling Report

**Date:** 2026-07-21  
**Status:** Complete

---

## Narrative model

Each major page tells a short visual story:

1. **Atmosphere** — institutional context (blueprint / light)
2. **Hero claim** — headline + primary CTA
3. **Diagram / product visual** — how the system works
4. **Alternating bands** — feature → muted → blueprint → elevated
5. **Close** — CTA with subtle atmosphere

---

## Page-family storytelling

| Family | Story beat |
| --- | --- |
| Homepage | Platform orchestration → mission → philosophy → products → industries → trust |
| Company | Connected institutions hero → mission/vision/culture/philosophy bands |
| Products | ProductPair / ProductHero media → philosophy feature band |
| Technology | Orchestration hero → educational ContentBands with diagrams |
| Pricing | Dashboard console → commercial clarity |
| Resources | Knowledge cover + article cards with visual media strip |
| Careers / Contact | DomainScene heroes with atmosphere |

---

## Color storytelling

Brand blue / indigo / emerald / cyan appear through:

- Primary CTAs and nav
- Domain accent eyebrows and diagram strokes
- Card / shell accent hairlines
- Soft domain washes in atmosphere (never full-page tints)
