# R1.DS.3.1 — Brand Color Application Report

**Date:** 2026-07-21  
**Sprint:** Enterprise Brand Color Application & Visual Refinement  
**Status:** Complete

---

## Purpose

Apply the official AOVIAS Brand Color System across the public website without replacing the semantic token architecture established in R1.DS.2 / R1.DS.2.1 / R1.DS.3.

---

## Official palette → semantic roles

| Brand role | Name | Semantic token | Usage |
| --- | --- | --- | --- |
| Primary | Deep Enterprise Blue | `--primary` / `primary-*` | CTAs, links, active nav, focus ring, interactive chrome (~10–15%) |
| Secondary | Institutional Indigo | `--secondary` | Platform / technology supporting emphasis |
| Accent | Professional Cyan | `--accent` | AI / analytics / insights / selected diagrams only |
| Supporting | Enterprise Emerald | `--supporting` | Security, trust, compliance, success |
| Warning | Professional Amber | `--warning` | Caution states |
| Danger | Enterprise Red | `--error` / `--danger` | Destructive / error states |

---

## Application decisions

1. **Links and link-style buttons** use `text-primary` (not cyan).
2. **Nav active indicator** uses `--nav-indicator` → primary scale (not cyan).
3. **Focus ring** uses primary (`--ring` / `--focus-ring`) for global interactive chrome.
4. **Cyan** remains available as `--accent` and is scoped via `--domain-accent` on AI routes.
5. **Brand illustrations** consume `text-domain-accent` so product/technology pages pick up the correct accent without page-wide tints.
6. **Surfaces** stay cool institutional neutrals — no pure white canvas, no pure black dark canvas.

---

## Coverage

Applied through theme maps and shared components (Button, Link, Card, Hero, SectionSurface, MainNav, MegaMenu, Breadcrumbs, SiteFooter, IconWrapper tone `domain`, brand SVGs). Public marketing, product, technology, pricing, resources, company, and contact routes inherit the system via shells and `DomainAccentScope`.

---

## Outcome

The site presents a unified enterprise brand: deep blue for interaction, indigo for platform emphasis, cyan reserved for AI, emerald for trust/security — calm, premium, engineering-led.
