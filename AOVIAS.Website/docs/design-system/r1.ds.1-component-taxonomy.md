**Date:** 2026-07-21  
**Scope:** Semantic families and roles only — no token values

## Taxonomy map (16 families)

```
Design System
├── 01 Page Structure
├── 02 Typography
├── 03 Color                    ← R1.DS.2 (roles listed; values deferred)
├── 04 Spacing / Layout

├── 07 Icons

├── 12 Cards

├── 15 Media / Brand Visuals
├── 16 Products
```

Families 01–07 are **foundations** (tokens + layout primitives). Families 08–18 are **component roles**.

## Classification rules

1. Prefer **role** over folder when folders overlap (e.g. card in marketing still → Cards + Marketing).
2. Feature-only UI that is visibly distinct gets a role; pure content modules do not.
3. Misc / Utilities is for non-visual or infra chrome only.
