# R1.DS.2.1 — Theme Refinement Summary

**Date:** 2026-07-21

## What changed

Theme **values** in `themes.css` were refined for premium institutional contrast. Role **names** and the palette → theme → Tailwind pipeline are unchanged from R1.DS.2.

## Light

- Cooler, more distinct canvas → muted band → elevated card steps
- Hero plane separated from page canvas
- Borders carry a quiet primary tint
- Cyan reserved for focus ring + nav indicator
- Shadows favor hairline elevation

## Dark

- Stepped charcoal (canvas / surface / elevated)
- Cards lift off the page without neon atmosphere
- Primary wash for brand atmosphere (calmer than accent glow)

## Additive

- `--nav-indicator` / `bg-nav-indicator` for active navigation recognition

## SEO / edge mirrors

- `seoConfig.themeColor` → `#E9EEF4` / `#090C11`
- `global-error.tsx` dark mirrors updated
