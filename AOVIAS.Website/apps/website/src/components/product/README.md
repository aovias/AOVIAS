# Product Components

Reusable, data-driven product presentation blocks. No product-specific copy inside components.

Import: `import { ProductHero, MediaSlotView, … } from '@/components/product'`

## Media Slot Architecture

Every visual area accepts a typed `MediaSlot`:

- `image` / `screenshot` / `diagram`
- `video`
- `code`
- `placeholder`
- `custom` / `demo` / `animation`

Showcase: `/internal/design-system/product`

See `docs/design-system/product-components.md`.
