## Reductions applied

- Defer contact Form Engine (`ContactFormsBandLazy`, `ssr: false`)  
- Remove client boundary from `SiteLogo`  
- Package import optimization (lucide, framer-motion)  
- No feature removal; no Form Engine rewrite  

---

## Residual justification

Auth and checkout **must** ship the Form Engine for R1 flows. Exceeding 150 KB First Load on those routes is accepted for RC1 with this documentation. Marketing routes remain the primary Perf gate surface.
