# R1.8 — Environment Configuration Guide

**Date:** 2026-07-20  
**Status:** Complete

---

## Stages

| Stage | File | `NEXT_PUBLIC_APP_ENV` |
| --- | --- | --- |
| Development | `deployment/environments/.env.development` | `development` |
| Preview | `.env.preview.example` | `preview` |
| Staging (future) | `.env.staging.example` | `staging` |
| Production | `.env.production` / `.env.production.example` | `production` |

App schema: `apps/website/src/config/env.ts`  
Also: `apps/website/.env.example`

## Key variables

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical origin |
| `NEXT_PUBLIC_APP_ENV` | Environment posture |
| `NEXT_PUBLIC_*_API_URL` | Integration placeholders |
| `NEXT_PUBLIC_ANALYTICS_PROVIDER` | Telemetry provider id (`mock`) |
| `NEXT_PUBLIC_FF_*` | Feature flags |
| `MAINTENANCE_MODE` | Ops maintenance rewrite |
| `HOST_PORT` | Host bind for compose |

## Secrets

Never commit verification tokens, API keys, or registry credentials. Inject via CI secrets / secret manager in real production.
