# R1.5 — Integration Architecture Overview

**Date:** 2026-07-20  
**Phase:** R1.5 — Integration Readiness Layer

---

## Mission

Prepare the AOVIAS Public Website for Release 2 backend integration **without** connecting live APIs. Pages remain static in behavior; all future backend dependencies are abstracted behind SDK contracts.

## Layering

```text
Pages / Features
    ↓
Hooks (useIdentitySdk, …) / Form adapters
    ↓
SDK interfaces (@aovias/sdk)
    ↓
Registry (composition root)
    ↓
Adapters (mock today → HTTP in R2)
    ↓
Static catalogs / in-memory mocks
```

## Package

`packages/sdk` (`@aovias/sdk`) — shared contracts:

- `core` — result, errors, pagination, adapter meta, registry
- `identity` · `commerce` · `contact` · `knowledge` · `search`

## Website composition

- `src/registries/sdk-registry.ts` — DI / service resolution  
- `src/adapters/**` — mock implementations  
- `src/config/integration.ts` + `feature-flags.ts` + `env.ts`  
- `src/hooks/sdk` — registry accessors for client components  

## Non-goals (R1.5)

- No real HTTP to Identity/Commerce/Contact/Knowledge/Search  
- No payment providers  
- No email delivery  
- No GraphQL
