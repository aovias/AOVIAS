# R1.6 — Open Graph & Twitter Card Report

**Date:** 2026-07-20  
**Status:** Complete

---

## Generators

- Open Graph: `buildOpenGraph` (`lib/seo/opengraph.ts`)
- Twitter/X: `buildTwitterCard` (`lib/seo/twitter.ts`)
- Consumed exclusively via `createPageMetadata` (no duplicate manual tags)

## Shared fields

| Field | Open Graph | Twitter |
| --- | --- | --- |
| Title | Yes | Yes |
| Description | Yes | Yes |
| Image (1200×630) | Yes | Yes |
| Canonical URL | `og:url` | via page metadata |
| Site name / locale | Yes | — |
| Card type | — | `summary_large_image` |
| `@aovias` site/creator | — | Configured |

Central map: `seoConfig.ogImages` / `@/seo` `ogImages`.

## Consistency rule

Page title + description + image are passed once into `createPageMetadata`; OG and Twitter are derived together to prevent drift.

## Post-deploy validation

Use Facebook Sharing Debugger and Twitter Card Validator on production URLs for home, products, technology, company, resources, pricing, careers, contact.
