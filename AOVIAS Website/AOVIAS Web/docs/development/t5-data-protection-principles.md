# T5 — Data Protection Principles

**Date:** 2026-07-20

---

| Principle | Intent |
| --- | --- |
| Data minimization | Collect and retain for clear purpose |
| Secure handling | Care across platform workflows |
| Encryption philosophy | Protect in transit and at rest (intent, not mechanisms) |
| Data lifecycle awareness | Create, use, retain, retire |
| Confidentiality | Need-to-know access |
| Integrity | Authorized change only |
| Availability | Usable for authorized work when needed |
