# R1 — Before vs After Assessment (Visual Design Review)

**Date:** 2026-07-21

---

## Side-by-side

| Moment | Before | After |
| --- | --- | --- |
| Page close | Pale gray card CTA, easy to miss | Dark navy enterprise band with blueprint texture, glow, light CTA |
| Philosophy / value grids | Plain white boxes | Accent marker bars / tinted icon containers per card |
| Statistics | Dark gray numbers on gray | Accent-colored values on tinted gradient surfaces |
| Quote | Small text, no framing | Accent border, oversized quote mark, lead type |
| Trust badges | Uniform gray pills | Emerald / blue / indigo semantic identities |
| Section bands | Soft blue invisible against white | Deepened `surface-section`; rhythm clearly visible |
| Pricing | Featured plan barely marked | Premium accent, primary ring, blue heading-scale price |
| Forms | Thin, flat fields | Shadowed, taller fields with primary hover/focus |
| Eyebrows | Colored label only | Accent rule + label — recurring brand signature |

## Executive re-review (after)

- **CEO / first-time visitor** — the page now closes as strongly as it opens;
  the dark CTA + footer sequence feels deliberate.
- **CIO / Enterprise Architect** — category color is legible: blue product,
  purple Studio, emerald security, cyan AI; statistics stand out.
- **Hospital Director / Government Officer** — still calm and restrained; no
  neon, no gimmicks — color is informative, not decorative.

## Quality gate

Measured against Microsoft / IBM / Stripe / Atlassian expectations: the site
now sustains brand presence through the entire scroll, not just at the hero
and footer. Maturity, clarity, and institutional trust — met.
