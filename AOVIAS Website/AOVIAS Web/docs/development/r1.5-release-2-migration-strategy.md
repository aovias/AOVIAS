# R1.5 — Release 2 Migration Strategy

**Date:** 2026-07-20

---

## Principle

Replace **adapters only**. Keep `@aovias/sdk` interfaces, FormEngine bindings, and page UIs stable.

## Steps per service

1. Implement `createHttp*Client(baseUrl)` conforming to the same interface  
2. Register it in `sdk-registry.ts` when `featureFlags.*Live === true`  
3. Set `NEXT_PUBLIC_*_API_URL` and flip the live flag per environment  
4. Map HTTP errors → `SdkError` / existing domain result shapes  
5. Keep mock adapter available for local/dev and tests  

## Suggested order

1. Contact (lowest risk)  
2. Identity (session cookies / CSRF)  
3. Commerce / Checkout consolidation  
4. Knowledge CMS  
5. Hosted Search  

## Do not

- Call `fetch` from pages or presentational components  
- Fork FormEngine contracts per provider  
- Remove mock adapters until HTTP adapters pass contract tests
