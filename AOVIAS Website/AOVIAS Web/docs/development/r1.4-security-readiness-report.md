# R1.4 Security Readiness Report (Frontend)

**Date:** 2026-07-20  
**Scope:** Frontend headers, client leakage, link hygiene — **not** backend auth providers

---

## Verdict

**Pass for RC1 frontend hardening.** Enforceable CSP baseline + HSTS (prod) + standard hardening headers ship from `next.config.ts`.

---

## Headers (verified on `http://127.0.0.1:3000/`)

| Header | Value |
| --- | --- |
| Content-Security-Policy | Baseline: `default-src 'self'`; `frame-ancestors 'none'`; `object-src 'none'`; img/font/script/style allowances for Next + themes |
| Strict-Transport-Security | `max-age=63072000; includeSubDomains; preload` (production) |
| X-Content-Type-Options | `nosniff` |
| Referrer-Policy | `strict-origin-when-cross-origin` |
| Permissions-Policy | camera/mic/geo/payment/usb disabled |
| X-Frame-Options | `DENY` (aligned with `frame-ancestors 'none'`) |
| X-Powered-By | Removed (`poweredByHeader: false`) |

## CSP notes

- Allows `'unsafe-inline'` / `'unsafe-eval'` for Next runtime + next-themes — **tighten with nonces iteratively** post-RC  
- Compatible with Next Image, self-hosted fonts, manifest  
- `upgrade-insecure-requests` in production
