# R1.7 — Analytics SDK Overview

**Date:** 2026-07-20  
**Status:** Complete

---

## Public API

Import from `@/telemetry` only.

| API | Role |
| --- | --- |
| `getTelemetryClient()` | Singleton client |
| `createTelemetryClient()` | Compose providers |
| `useTelemetry()` | React access |
| `useTrackEvent()` | Stable track callback |
| `usePageView()` / `PageViewTracker` | Route instrumentation |
| `TelemetryProvider` | Context + consent injection |

## Client capabilities

- `track` / `trackCustom`
- `trackPageView`
- `trackConversion`
- `trackError`
- `trackNavigation`
- `startSpan` / `endSpan` / `startTrace`
- `setConsent` / `getConsent`
- `setCampaign` / `getContext` / `getSession`

## Provider contract

```ts
interface AnalyticsProvider {
  id: string;
  displayName: string;
  transmits: boolean;
  track(event: TelemetryEvent): void | Promise<void>;
  // optional: init, pageView, identify, flush, shutdown
}
```

## R1 sink

`MockAnalyticsProvider` — in-memory ring buffer, optional `console.debug` when `NEXT_PUBLIC_TELEMETRY_DEBUG=true`.

## Non-goals (R1)

- No Google Analytics, PostHog, Mixpanel, Clarity, or Plausible packages
- No network calls from the telemetry layer
- No page imports of provider IDs
