# R1.8 — Production Deployment Architecture

**Date:** 2026-07-20  
**Status:** Complete

---

## Model

Immutable container deployments of the Next.js **standalone** server, configured by environment, operated through health probes, aligned with future AOVIAS platform services.

```text
deployment/
├── docker/           Multi-stage Dockerfile (runner / development)
├── compose/          Dev + production compose files
├── environments/     Non-secret env templates per stage
├── nginx/            Optional reverse proxy
├── scripts/          One-command deploy + validation
├── github/           CI notes (workflow lives in .github/workflows)
├── monitoring/       Provider-agnostic monitoring notes
├── health/           Probe documentation
└── docs/             Operator-facing guides
```

## Runtime path

```
Client → (optional nginx) → Next.js standalone (node, non-root)
                              ├─ /api/health  (liveness)
                              └─ /api/ready   (readiness)
```

## One-command deploy

```bash
npm run deploy:local
```

## Principles

- Infrastructure as Code under `deployment/`
- Configuration over hardcoding (`deployment/environments`)
- Least privilege (non-root user `nextjs`, `no-new-privileges`)
- No secrets in git
- CI validates image before deploy-prep artifact
