# R1 — Component Color Assignment Report

**Date:** 2026-07-21
**Rule:** every treatment uses existing semantic tokens; no hardcoded colors,
no new design language.

---

## Component → color responsibility map

| Component | Treatment | Tokens |
| --- | --- | --- |
| Header | Glass chrome, blue-gray wash, scroll accent hairline | `nav-background`, `primary-muted`, `primary` |
| Mega menu | Elevated panel, top accent, hover tint, icon → primary on hover | `nav-mega-background`, `primary`, `primary-muted` |
| Breadcrumb | Muted trail, primary current page | `breadcrumb-foreground`, `breadcrumb-current` |
| Hero | Rich blueprint atmosphere, radial light, accent glow | `brand-atmosphere`, `domain-accent`, `surface-hero` |
| Section (soft blue) | Deepened `--surface-section` for visible rhythm | `surface-section` |
| **CTA band (dark)** | Navy gradient + blueprint texture + brand glow; light primary CTA | `brand-950/900`, `primary`, `brand-50` |
| Card (base) | Gradient surface + domain top hairline | `card`, `surface-elevated`, `domain-accent` |
| Card (category) | `accent` prop → bolder top bar + corner tint | `[data-accent]` → `domain-accent` |
| Product card | Command → blue, Studio → purple, Platform → indigo | `primary-500`, purple, `secondary-500` |
| Technology / AI / Security / Resources cards | Inherit page domain scope: indigo / cyan / emerald / slate | `DomainAccentScope` |
| Value / Principle card | Accent icon container or accent marker bar | `domain-accent` |
| Statistic | Accent value + tinted gradient surface | `domain-accent`, `primary-muted` |
| Quote | Accent left border + oversized quote mark, lead type | `domain-accent` |
| Trust badge | security → emerald, compliance → blue, quality → indigo tints | `success`, `primary-muted`, `secondary-muted` |
| Badge (chip) | Tinted fill + matching border per variant | `primary`, `secondary-muted`, status tokens |
| Pricing card (featured) | Premium accent, primary ring, primary price, floating shadow | `accent="premium"`, `primary` |
| Button hierarchy | primary (solid) > secondary (tint) > outline > ghost > link | `primary`, `secondary-muted` |
| Input / Textarea / Select | Surface shadow, primary hover/focus border, taller field | `input-*`, `primary`, `shadow-surface` |
| Section eyebrow | Accent rule + accent label | `domain-accent` |
| Footer | Dark navy brand close (from R1.VA.2) | `brand-950/900`, `primary` |

## Distribution check

Neutral surfaces still carry ~65% of every viewport; primary blue anchors
chrome, CTAs and emphasis (~20%); domain accents identify categories (~10%);
interactive highlights stay ~5%. Color guides attention — it does not decorate.
