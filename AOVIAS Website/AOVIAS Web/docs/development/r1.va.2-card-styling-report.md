# R1.VA.2 — Card Styling Report

**Date:** 2026-07-21
**Milestone:** M4 (Card personality) + M7 (Domain identity)
**Status:** Complete

---

## Goal

Move cards away from a single uniform look toward a restrained, category-aware
personality system — no bright colors, no gratuitous gradients.

## Card primitive (`components/primitives/display/card.tsx`)

- Added an optional `accent` prop (`CardAccent`): `blue | indigo | cyan |
  emerald | slate | purple | premium`.
- When set, the card renders `data-accent`, which resolves `--domain-accent`
  through CSS wiring, driving:
  - a **bolder top accent bar** (`h-0.5`, domain gradient), and
  - a **faint corner tint** (`domain-accent/[0.07]`) for depth.
- Without `accent`, cards inherit the page's `DomainAccentScope` accent via the
  existing base top-hairline — so category identity is automatic on domain pages.
- Base variants keep gradient surfaces (`default`, `elevated`, `interactive`) and
  `rounded-xl` for radius consistency.

## Accent wiring (`packages/design-system/src/css/themes.css`)

Category → token map (sets only `--domain-accent`, never a page background):

| Accent | Token |
| --- | --- |
| blue | `primary-500` |
| indigo | `secondary-500` |
| cyan | `accent-500` |
| emerald | `supporting-500` |
| slate | `neutral-500` |
| purple | `#6b5b95` |
| premium | `primary-600` |

## Category mapping (M7)

- **Products** — Command → Blue, Studio → Purple, Platform → Indigo
  (`features/products/catalog/section.tsx`).
- **Technology / AI / Security / Engineering** — inherit indigo / cyan / emerald /
  navy from each page's `DomainAccentScope` (no per-card wiring needed).
- **Knowledge / Resources** — slate; **Pricing** — premium highlight.

## Iconography

- `IconWrapper tone="domain"` picks up the resolved accent, so card icons match
  their category automatically.

## Guardrails

- Accents applied only to bars, tints, icons, and borders — never full fills.
- `FeatureCard` forwards `accent` optionally; all existing usages remain valid.

## Validation

- Verified Command (blue) and Studio (purple) accent bars on the live products
  catalog; icon tones match.
