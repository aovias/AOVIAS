## Theme deltas (high level)

### Light

- Canvas shifted slightly cooler (`--background: #e8edf3`).
- `--ring` / `--nav-indicator` → primary (was accent/cyan).
- `--secondary` / `--supporting` steps tuned for clearer institutional hierarchy.
- Borders slightly stronger primary mix for depth without noise.

### Dark

- Canvas remains stepped charcoal (`#090c11` … elevated cards).
- `--ring` / `--nav-indicator` → primary light steps.
- Domain accents remapped to lifted counterparts (AI → accent-400 cyan; security → supporting-400; studio/architecture → soft purple).

---

## Explicit non-changes

- No new parallel color systems.
- No removal of semantic aliases (`background`, `card`, `domain-accent`, etc.).
- Typography / spacing / elevation from R1.DS.3 preserved.
