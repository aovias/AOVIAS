## Coverage statement

Every barrel export from `primitives`, `marketing`, `navigation`, `brand`, `product`, `forms`, `pricing`, `resources`, `trust`, `system-states`, and `layout` (plus `layouts/*`) appears above. Types-only and utility functions are omitted from visual roles.
