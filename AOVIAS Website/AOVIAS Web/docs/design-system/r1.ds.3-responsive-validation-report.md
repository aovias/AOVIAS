# R1.DS.3 — Responsive Validation Report

**Date:** 2026-07-21

## Approach

Fluid type (`clamp` on display/hero/page/section titles) and fluid section/hero vertical spacing remove most breakpoint-specific padding ladders. Container max-widths remain 1440 / 1760.

## Breakpoint intent

| Width | Expectation |
| --- | --- |
| 320–390 | Single column; titles clamp down; `py-hero-y` / section clamps compress |
| 768 | Two-column heroes engage where designed |
| 1024+ | Primary nav; mega menus; full grids |
| 1280–1440 | Content max comfortable |
| 1600–1920+ | Hero max + gutters; no stretched type beyond clamp ceiling |

## Verified (production `:3000`)

Desktop visual pass on home, product, technology/AI (screenshots). Fluid tokens apply automatically at mobile widths without separate arbitrary `text-[…]` classes.
