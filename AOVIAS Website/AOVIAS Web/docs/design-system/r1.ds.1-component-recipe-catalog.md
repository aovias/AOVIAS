# R1.DS.1 — Component Recipe Catalog

**Date:** 2026-07-21  
**Constraint (original):** Roles only — **no** color, type-scale, or spacing **values**  
**R1.DS.2:** Semantic color (and type role) **values** are now assigned in `packages/design-system` and documented under `r1.ds.2-*`. Recipe **role names** below remain the contract.

Each recipe: Purpose · Usage · Composition · Children · Variants · States · Future token dependencies

---

## How to read token dependencies

Examples of allowed roles: `color.surface`, `color.ink`, `type.heading.h1`, `type.body.md`, `space.section-y`, `space.stack-md`, `elevation.raised`, `radius.md`, `motion.reveal`, `breakpoint.md`, `z.header`, `icon.size.md`.
