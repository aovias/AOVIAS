# R1.DS.2.1 — Before vs After Visual Assessment

**Date:** 2026-07-21  
**Nature:** Qualitative brand assessment (architecture held constant)

| Dimension | Before (post R1.DS.2) | After (R1.DS.2.1) |
| --- | --- | --- |
| Flatness | Surfaces close; bands subtle | Clearer canvas → muted → elevated steps |
| Hero presence | Soft but similar to canvas | Distinct `surface-hero` plane |
| Brand recognition | Deep blue present | Deepened primary/secondary; cyan for focus/nav only |
| Navigation current page | Colour change only | Colour + cyan indicator underline |
| Domain identity | Eyebrows mostly | Eyebrows + icons via `domain` accent |
| Cards | Tokenized but generic lift | Surface-first depth; card-title type |
| Dark theme | Dark but flatter card/canvas | Stepped charcoal elevation |
| Startup / neon risk | Accent-forward atmosphere (dark) | Primary wash; restrained cyan |

## Brand outcome

Closer to institutional Microsoft/IBM/Stripe maturity: calm confidence, engineering excellence, without fragmenting the brand with loud product tints.
