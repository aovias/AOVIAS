## Trust accents

`--trust-security`, `--trust-compliance`, `--trust-privacy`, `--trust-verified` — available for badges/sections; status tones remain for alerts.

## Path wiring

| Path prefix | Attribute |
| --- | --- |
| `/technology`, `/technology/platform/*` | `data-technology=platform` |
| `/technology/engineering/*` | `engineering` |
| `/technology/ai/*` | `ai` |
| `/technology/trust/*` | `trust` → security accent |
| `/solutions/[slug]` | `data-industry=[slug]` |

Accents never dominate the page; they tint eyebrows and optional accents only.
