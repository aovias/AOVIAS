# R1.DS.2 — Semantic Color Token Library

**Date:** 2026-07-21  
**Source:** `packages/design-system/src/tokens/colors.ts` + `css/tokens.css` + `css/themes.css`

---

## Architecture

```
Palette primitives (--palette-*)
        ↓
Semantic theme roles (--background, --primary, --domain-accent, …)
        ↓
Tailwind @theme (--color-*) → utilities (bg-primary, text-ink, …)
```

Components consume **semantic utilities** only. Palette hex lives only in the design-system package.

---

## Brand scales

| Scale | Intent | CSS prefix |
| --- | --- | --- |
| Primary | Deep enterprise blue | `--palette-primary-*` |
| Secondary | Indigo (restrained) | `--palette-secondary-*` |
| Accent | Cyan (interactive / focus) | `--palette-accent-*` |
| Supporting | Emerald | `--palette-supporting-*` |

## Neutral scale

`--palette-neutral-0` … `1000` — near-white extreme at `0` (not pure `#FFFFFF`); deep charcoal at `1000` (not pure black). Theme surfaces use `50+` / elevated near-white.

## Status scales

| Role | Palette | Theme alias |
| --- | --- | --- |
| Success | supporting/emerald | `--success*` |
| Warning | amber | `--warning*` |
| Danger | red | `--error*` ≡ `--danger*` |
| Info | blue | `--info*` |

## Core semantic roles

| Role | CSS var | Tailwind |
| --- | --- | --- |
| Page canvas | `--background` | `bg-background` |
| Surface | `--surface` | `bg-surface` |
| Elevated / card | `--surface-elevated`, `--card` | `bg-surface-elevated`, `bg-card` |
| Hero / section | `--surface-hero`, `--surface-section` | `bg-surface-hero`, `bg-surface-section` |
| Muted / subtle | `--muted`, `--subtle`, `--surface-muted` | `bg-muted`, `bg-subtle`, … |
| Ink | `--ink` / `--foreground` | `text-ink`, `text-foreground` |
| Muted ink | `--ink-muted` | `text-ink-muted` |
| Border / divider | `--border`, `--border-strong`, `--divider` | `border-border`, `bg-divider` |
| Focus | `--ring`, `--focus-ring` | `ring-ring`, `ring-focus-ring` |
| Brand | `--primary`, `--secondary`, `--accent` | `bg-primary`, … |
| Atmosphere | `--brand-atmosphere` | `bg-brand-atmosphere` |
| Overlay | `--overlay` | `bg-overlay` (via var) |
| Domain accent | `--domain-accent` | `text-domain-accent` |

## Domain accent catalogs

Product: `platform`, `command`, `studio`, `future`  
Technology: `platform`, `engineering`, `ai`, `security`, `identity`, `architecture`  
Industry: `healthcare`, `government`, `education`, `enterprise`  
Trust: `security`, `compliance`, `privacy`, `verified`

Activated via `data-product` / `data-technology` / `data-industry` on shells (`DomainAccentScope`).

## Compatibility

Existing utilities (`bg-primary`, `bg-error`, `text-muted-foreground`, …) remain valid aliases of the expanded role set.
