**Date:** 2026-07-21  
**Status:** Complete

---

## Semantic surface ladder

| Role | Token | Light intent |
| --- | --- | --- |
| Background | `--background` | Cool institutional canvas |
| Surface / section | `--surface` / `--surface-section` | Default band |
| Muted | `--surface-muted` / `--muted` | Recessed band |
| Subtle | `--surface-subtle` | Soft contrast step |
| Elevated / card | `--surface-elevated` / `--card` | Lifted content |
| Hero | `--surface-hero` | Intro atmosphere |
| Border / divider | `--border` / `--divider` | Hairline structure |
| Overlay | `--overlay` | Modal / dialog scrim |

---

## SectionSurface tones

| Tone | Use |
| --- | --- |
| `canvas` | Background band |
| `muted` | Recessed content |
| `subtle` | Soft alternate |
| `elevated` | Lifted band + surface shadow (**new**) |
| `tint` / `contrast` | Restrained primary-muted emphasis |
| `blueprint` | Grid texture for engineering sections |

---

## Homepage rhythm (applied)

Mission → muted → Philosophy → blueprint → Products → elevated → Industries → muted → Trust → contrast → Security / Resources → canvas.

This removes flat “one-slab” pages without inventing decorative noise.

---

## Cards

Card variants use `--card` fill with `shadow-surface` / `shadow-raised`. Interactive hover strengthens primary-tinted border and raised shadow for clear affordance.

---

## Atmosphere

`BrandAtmosphere` continues to use soft gradients + blueprint grid masked to the hero — appropriate density, never page-dominant.
