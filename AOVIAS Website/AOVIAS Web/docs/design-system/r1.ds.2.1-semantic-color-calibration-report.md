# R1.DS.2.1 — Semantic Color Calibration Report

**Date:** 2026-07-21  
**Constraint:** Architecture from R1.DS.2 unchanged — values and application only

---

## Intent

Calibrate the existing semantic token maps so the site reads as institutional, premium, and calm — not flat, monochrome, or startup-saturated.

## Light theme calibration

| Role | Direction |
| --- | --- |
| `--background` | Cooler institutional canvas `#E9EEF4` |
| `--surface` / `--surface-section` | Clear mid step `#F2F5F8` |
| `--surface-elevated` / `--card` | Near-white `#FAFBFC` (not pure white) |
| `--surface-muted` / `--subtle` | Stronger alternating band contrast |
| `--surface-hero` | Distinct hero plane `#DFE8F1` |
| Borders / divider | Primary-tinted mixes (softer brand cohesion) |
| `--primary` | Remains deep enterprise blue |
| `--accent` / `--ring` | Cyan deepened (`accent-700` / `600`) for focus, not fills |
| `--secondary` | Indigo deepened for restraint |
| Shadows | Hairline + soft lift (surface over drop) |

## Dark theme calibration

| Role | Direction |
| --- | --- |
| Canvas | `#090C11` deepest |
| Elevated / card | `#161B23` stepped up |
| Hero / muted | Distinct mid charcoal steps |
| Ink | `#EEF1F5` |
| Atmosphere | Primary wash (not neon accent) |
| Shadows | Soft + faint light hairline |

## New role (additive, same architecture)

| Role | Purpose |
| --- | --- |
| `--nav-indicator` | Active nav underline (cyan, restrained) |
