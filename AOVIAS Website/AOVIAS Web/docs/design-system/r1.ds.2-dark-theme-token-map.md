# R1.DS.2 — Dark Theme Token Map

**Selector:** `[data-theme='dark']`  
**File:** `packages/design-system/src/css/themes.css`

| Semantic role | Dark mapping |
| --- | --- |
| `--background` | `neutral-1000` (`#0B0E13`) |
| `--surface` / `--card` | `neutral-950` |
| `--surface-elevated` | `neutral-900` |
| `--surface-muted` / `--muted` | `#12151c` |
| `--surface-hero` | `#10141b` |
| `--foreground` / `--ink` | `neutral-50` |
| `--muted-foreground` / `--ink-muted` | `neutral-400` |
| `--ink-inverse` | `neutral-1000` |
| `--border` | `neutral-800` |
| `--border-strong` | `neutral-700` |
| `--primary` | `primary-200` (lightened for contrast) |
| `--primary-foreground` | `primary-950` |
| `--secondary` | `secondary-300` |
| `--accent` | `accent-400` |
| `--ring` | `accent-400` |
| Status fills | `*-500` with translucent `*-subtle` |
| `--overlay` | `rgba(0, 0, 0, 0.64)` |
| `--brand-atmosphere` | accent mix ~14% |
| Domain accents | lightened counterparts for contrast |

Components are identical across themes; only this map changes. SEO `themeColor.dark` = `#0B0E13`.
