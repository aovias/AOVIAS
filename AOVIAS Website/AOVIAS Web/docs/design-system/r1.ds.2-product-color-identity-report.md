# R1.DS.2 — Product Color Identity Report

**Date:** 2026-07-21

## Product accents (subtle)

| Product | Token | Light value (role) |
| --- | --- | --- |
| AOVIAS Platform | `--product-platform` | deep blue |
| AOVIAS Command | `--product-command` | cyan |
| AOVIAS Studio | `--product-studio` | indigo |
| Future products | `--product-future` | emerald |

## Activation

`DomainAccentScope` sets `data-product` from pathname:

- `/products` → `platform`
- `/products/command` → `command`
- `/products/studio` → `studio`
- other product slugs → `future`
- `/pricing`, `/checkout` → `platform`

CSS maps `data-product` → `--domain-accent`.

## Usage (restrained)

- Hero / page eyebrows: `text-domain-accent`
- Icons / underlines may use the same role
- **Never** used as full-page background washes

Components remain shared; identity is token-driven only.
