# 15 — Visual Governance

**AVLS v1**

## Authority order

1. AVLS (this folder)  
2. Written Doctrine (when populated)  
3. Creative Direction frames (inspiration / evidence)  
4. Design System tokens & components  
5. Individual PR taste  

## PR checklist (visual changes)

- [ ] Cites AVLS section + frame ID(s)  
- [ ] Uses named EBAS / hero / illustration registry IDs  
- [ ] Obeys one accent per viewport  
- [ ] No new one-off background CSS  
- [ ] No component duplication  
- [ ] Light + dark checked  
- [ ] Typography remains primary  
- [ ] `prefers-reduced-motion` respected if motion added  

## Change control

| Change type | Requires |
|-------------|----------|
| New EBAS variant | AVLS registry update + design review |
| New illustration category | Illustration registry + stroke rules check |
| Token hex shift | Design System governance + contrast audit |
| Page visual application | Phase roadmap item (V2+) |

## Accessibility

- Focus rings mandatory (e2 double-ring intent → existing focus tokens)  
- Contrast AA minimum for text  
- Decorative atmospheres `aria-hidden`  
- Never encode meaning in color alone  

## Quality bar

Comparable restraint to Microsoft / IBM / Stripe / Atlassian / GitHub Enterprise / Linear — **without copying** their language. AOVIAS remains the engineering-journal institutional voice.
