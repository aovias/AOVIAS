# 07 — Product Visualization System

**AVLS v1** · Sources: `03_command_*`, `c3_studio_*`, `e3`, product refined heroes

## Goals

Product visuals must communicate **operational excellence** and **delivery discipline** — not consumer SaaS playfulness.

## Command

| Aspect | Spec |
|--------|------|
| Accent | `#4A6FA5` |
| Motif | Operations terminal / governance console |
| Atmosphere | `workflow` or Command-blue domain wash |
| Diagram modes | Governance hero, operations interior |
| Feel | Control, visibility, continuity |

## Studio

| Aspect | Spec |
|--------|------|
| Accent | `#D9CFC0` (editorial cream — restrained) |
| Motif | Workstation + blueprint sheets |
| Atmosphere | Soft workflow / parchment-adjacent cards |
| Feel | Design → standards → handoff |

## Platform (shared)

| Aspect | Spec |
|--------|------|
| Motif | Central core + satellite capabilities |
| Diagram | Isometric ecosystem (`d1`) |
| Atmosphere | `platform` |

## Rules

1. Product accent appears in icon, terminal glow, or top card hairline — **not** full-bleed page tint.  
2. Mock UI inside frames stays schematic (blocks/labels), not realistic screenshots, unless approved.  
3. Pair Command + Studio only when teaching portfolio coherence (homepage / products index).  
4. Roadmap products use quieter slate treatment until available.
