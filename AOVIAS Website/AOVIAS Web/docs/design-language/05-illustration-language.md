# 05 — Illustration Language

**AVLS v1** · Sources: `09_illustration_language`, `e4_hero_illustration_rules`, product frames

## Metaphor

Bauhaus-era engineering journal → modern enterprise.

## Technical rules (normative)

| Rule | Value |
|------|-------|
| Stroke weight | **1.25px** single weight |
| Perspective | **Isometric locked at 30°** (product / platform) |
| Fills | **Outlines only** — no gradient fills in line illustrations |
| Structure ink | Platinum @ **~60% opacity** |
| Accent | **One** domain/product accent highlight per illustration |
| Background of artboard | Void, parchment, or card surface — never competing pattern noise inside the art |

## Allowed motifs (from moodboard)

| Motif | Meaning |
|-------|---------|
| Isometric server rack | Infrastructure |
| Workflow token / path | Orchestration |
| Knowledge graph | Relationships / RAG |
| Security envelope + orbitals | Protection |
| AI reasoning loop | Intelligence |
| Enterprise globe | Global institutional reach |

## Product visualization cues

| Product | Motif |
|---------|-------|
| Command | Retro/modern ops terminal |
| Studio | Laptop + blueprint sheets |

## Forbidden

- Character mascots  
- 3D glossy marketing renders as default  
- Multi-color filled isometric cities  
- Photographic product shots as primary brand illustrations  
- Stroke weights that vary arbitrarily within one illustration  

## Theme variants

| Theme | Treatment |
|-------|-----------|
| Light | Platinum lines on inverse/parchment; accent status light |
| Dark | Platinum lines on void; stronger localized glow on accent node |

## Component mapping

Map to existing `BrandShell`, domain scene components, `MediaSlot`, and product consoles — do **not** duplicate illustration systems. See [visual-component-mapping.md](./visual-component-mapping.md).
