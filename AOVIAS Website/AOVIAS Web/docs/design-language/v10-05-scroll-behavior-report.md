# Phase V10 — Scroll Behavior Report

## Principles

Scrolling creates editorial rhythm without hijacking.

## Retained

- `MotionReveal` / `MarketingReveal` / `MotionStagger` — once-per-view progressive reveals
- Section awareness (TOC / product nav) — tracking only, not decorative parallax
- Header scroll elevation — subtle chrome response

## Explicitly avoided

- Scroll hijacking
- Full-page snap
- Heavy parallax
- Continuous scroll-linked animation

## Result

Natural scroll with calm section pacing.
