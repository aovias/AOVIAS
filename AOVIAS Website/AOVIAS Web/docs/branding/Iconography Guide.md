# AOVIAS Iconography Guide

## Two layers

| Layer | System | Use |
| --- | --- | --- |
| UI chrome | Lucide | Navigation, forms, site actions |
| Product identity | AOVIAS product icons | Command, Studio, future products, marketing |

Do **not** invent a second UI icon set for the website.

## Product icons

- Geometric, blueprint stroke language  
- Readable at 16px  
- SVG masters + PNG sizes: 16–512  
- Location: `assets/brand/icons/`

## Favicons / app icons

Derived from the corporate mark — see `assets/brand/favicons/` and `app-icons/`.
