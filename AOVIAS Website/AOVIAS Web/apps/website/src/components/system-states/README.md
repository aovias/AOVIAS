# System States

Reusable non-happy-path presentation for empty, error, loading, maintenance, and related states.

Import: `import { EmptyState, ErrorState, LoadingState, … } from '@/components/system-states'`

Composes primitives (`Spinner`, `Skeleton`) and marketing CTAs. No page-specific copy or retry logic.

Showcase: `/internal/design-system/system-states`

See `docs/design-system/system-states.md`.
