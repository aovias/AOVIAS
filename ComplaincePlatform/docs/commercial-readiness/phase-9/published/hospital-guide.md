# Hospital Guide — AOVIAS Command v1.0.0

**Audience:** Hospital owners, accreditation program sponsors, quality directors

## Why hospitals choose AOVIAS

AOVIAS Command replaces spreadsheet-driven accreditation prep with a single system of record for journeys, evidence, CAPA, and governance—optionally augmented by licensed AI.

## Program setup (recommended sequence)

1. **Onboard** organization and hospital; invite founding Quality Manager and IT admin.
2. **Activate license** for the SKU purchased (Core / +AI / Governance / Enterprise).
3. **Select frameworks** and map chapters/elements to departments.
4. **Assign ownership** so every measurable element has a responsible department head.
5. **Baseline evidence** collection windows and review cadences.
6. **Schedule management review** using governance modules when entitled.

## Role homes (what leadership should expect)

| Role | Sees |
|------|------|
| Hospital Owner | Portfolio readiness, licensing posture, executive summaries |
| Quality Manager | Journey progress, deficiencies, CAPA, audit prep |
| Department Head | Assigned standards, tasks, evidence owed |
| Consultant | Multi-facility advisory views (policy-dependent) |
| Auditor | External/internal audit workspace |

## Accreditation cadence

- Pre-assessment: close evidence gaps; keep journeys out of “false green.”
- Mock audit: use Demo/seed scenarios or staging; never corrupt production PHI.
- Assessment window: freeze evidence via lifecycle submission rules; track CAPAs separately.
- Post-assessment: management review package + residual risk updates.

## Success metrics

- % elements with current evidence
- Open CAPA aging
- Overdue department tasks
- License seat utilization
- (Enterprise) ACE readiness insight trend—if entitled
