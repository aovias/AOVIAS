# Onboarding Success Milestones

**Product:** AOVIAS Command v1.0.0  
**Audience:** Customer Success + hospital sponsor

Milestones are contractual / pilot acceptance gates — not vanity metrics.

## M0 — Environment ready (Day 0)

| Criterion | Evidence |
|-----------|----------|
| Platform reachable (Gateway + WebApp) | URL + health |
| License Active (or Grace with plan) | `/licenses/status` |
| Admin + QM can log in | Live login |
| Backup path documented | Ops note |

**Exit:** Safe to train users.

## M1 — Program bootstrapped (≤ 7 days)

| Criterion | Evidence |
|-----------|----------|
| Framework active + journey enrolled | Screenshots / IDs |
| ≥ 1 department with OE ownership | Ownership matrix |
| ≥ 5 evidence items uploaded | Journey evidence list |
| Seat usage within MaxSeats | `/licenses/usage` |

**Exit:** Pilot acceptance for “configured and usable.”

## M2 — Operational rhythm (≤ 30 days)

| Criterion | Evidence |
|-----------|----------|
| Tasks / CAPA used for real findings | Open CAPA list |
| At least one audit session or schedule entry | Audit UI |
| Scoring / dashboard reviewed by Owner or QM | Health review notes |
| Support ticket path exercised once | Ticket ID or diagnostics download |

**Exit:** Hospital runs weekly quality rhythm in-product.

## M3 — Accreditation readiness signal (≤ 90 days)

| Criterion | Evidence |
|-----------|----------|
| Evidence coverage meeting agreed % for in-scope chapters | Score / coverage report |
| CAPA aging under agreed threshold | CAPA aging metrics |
| Management review packet produced from platform | MR / dashboard export |
| Renewal intent discussed | CS renewal note |

**Exit:** Candidate for case study (anonymized) + commercial renewal conversation.

## Anti-goals

- Do not claim M3 without real hospital data (demo seeds do not count).
- Do not redefine journey status outside ComplianceLifecycleStateMachine.
- Payments / self-serve renewals are **out of scope** for v1.0.0 milestones.
