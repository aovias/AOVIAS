# Phase 40 — Wave 2: Recommendation, actions, metrics, charts + verification

## Goal (backward from success)

**Recommendation panel** copy and footer line align with reference *structure*: primary insight line, **Go to OE** / **View Details**, warning line with **high-risk OE count** and **last activity** phrasing derived from **real** store data where possible. **Action bar** shows **visible** Lucide icons (play, history, alert-triangle) on primary / secondary / danger. **Metric** and **chart** cards use **darker surfaces**, **bolder metric values**, and clearer title hierarchy per gap analysis — all token-safe. **`DESIGN_RULES.md`** gains a short **“Journey dashboard (mode selection)”** note if new patterns are introduced.

## must_haves

- [ ] `buildRecommendationVm()` (or template inputs): summary text **tone** matches reference (actionable OE / compliance) using **existing** snapshot fields; no fabricated API IDs — if data missing, use concise fallback that matches reference *style* (document in code comment).
- [ ] Recommendation footer: pattern like **`{{ highRiskCount }} High Risk OEs need attention • Last activity: {{ lastActivity }}`** (exact wording adjustable) with `highRiskCount` from real high-risk signal (existing `filteredChapters` or store helper — **do not** hardcode `2`).
- [ ] `recommendation-panel`: optional lightbulb / warning icons via **ng-icons** if not present; token styling.
- [ ] `action-bar`: add **NgIcon** per button tier; keep behavior identical.
- [ ] `metric-card` + `chart-card`: increase **value** / title contrast per gap doc; card background step using `--color-bg-surface` / `--bg-tertiary` tokens.
- [ ] `journey.component.html`: wire recommendation `lastActivity` from computed or store (replace generic “Last sync: active session” if a better field exists).
- [ ] `40-VERIFICATION.md` checklist mapping gap doc sections 2–6 to ✅.
- [ ] Build + lint pass.

## Non-goals

- Full chart library swap (keep mini trend list unless already chart component).
- Shell-level module tabs (PLANNING / IMPLEMENTATION) from alternate reference image.
