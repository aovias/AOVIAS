### Store coupling

- `refreshObjectiveElementDetail(oeId)` is **private** today. Minimal options: (a) add **one** public method on `JourneyWorkspaceStore` e.g. `refreshSelectedObjectiveElementFromApi()` delegating to the private refresh, or (b) call an existing public loader if one exists. **Prefer (a)** — single wrapper, no duplicate HTTP.

Wizard bulk should **not** duplicate long-term — Phase 54.2 may call **service** from wizard for bulk while single could eventually converge on store; plan keeps **wizard → JourneyDataService** for both to avoid refactoring store in Wave 1 (user: minimal change).

### Bulk response shape

- Current `RegisterOeEvidenceResponseDto` is `{ evidenceId? }` (single-upload shape).
- Product brief: bulk returns `successCount`, `failureCount`, `items[]`. **Confirm** against Gateway OpenAPI or sample JSON before typing; add **`BulkEvidenceUploadResponseDto`** (or optional fields) in `journey-api.model.ts` only when contract is confirmed — otherwise parse defensively with optional chaining and generic success copy.
