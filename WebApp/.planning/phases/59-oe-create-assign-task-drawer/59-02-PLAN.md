# Phase 59 — Wave 2: Reactive form, validation, multi-assign, attachments, Tailwind/token styling

## Goal

Replace section placeholders with a **full reactive form** bound to **`taskAssignmentDraft`** (two-way via store patch or local `FormGroup` synced to store on change). Implement **inline validation** (title required; configurable min length), **multi-user assignment** with **avatars** (from `OrganizationService` members + `SessionService` userId), **priority** color-coded badges, **classification** fields, **linkage** read-only chips when prefilled from OE context, **attachments** UI (file picker + list; optional link to evidence library route). **Sticky footer** actions call store methods; **Create Task** validates and shows inline errors only. Optional **Tailwind** utilities for grid/flex **if** mapped in `styles.css` / theme — otherwise SCSS + tokens.

## must_haves

- [ ] **`FormGroup`** `taskForm` with controls: `title`, `description`, `tagInput` / `tags` FormArray, `assigneeIds`, `department`, `dueDate`, `priority`, `status`, `taskType`, `standardLabel` (readonly), `objectiveLabel` (readonly), `evidenceRequired`, `attachments` (FormArray of `{ name, size, file? }`).
- [ ] **Validators**: `title` — `Validators.required`, `Validators.minLength(2)`; show `mat-error` or styled span under field; **no** `window.alert`.
- [ ] **Assignment**: **MatAutocomplete** multi-select **or** chip list + dropdown pattern; selected users show **avatar** (image or initials pipe); max assignees cap (e.g. 10) with hint text.
- [ ] **Department**: select from `CommonLookupService` or departments on org context — if unavailable, text input placeholder + TODO comment.
- [ ] **Due date**: `MatDatepicker` or `input type="date"` with token-styled wrapper.
- [ ] **Priority / status / type**: `MatSelect` or segmented control; **priority** uses **semantic** classes: `priority--low|medium|high|critical` mapped to `--color-status-*` tokens.
- [ ] **Linkage section**: display **Standard** + **Objective** from draft; fields **disabled** when opened from wizard context (product: always show OE linkage); allow manual override only if product approves — default **readonly**.
- [ ] **Attachments**: replicate **oe-wizard** evidence UX subset: add file button, list rows, remove; store `File` handles in component until API exists; show total size hint.
- [ ] **Cancel**: close + optional “discard draft?” — **Wave 2 minimal**: discard without confirm if no dirty flag; optional `dirty` signal.
- [ ] **Reusable** `TaskDrawerSectionHeaderComponent` (icon + title + optional description).
- [ ] **Reusable** `AssigneeChipsFieldComponent` + **`PrioritySelectFieldComponent`** (optional split).
- [ ] Document in **`59-02-SUMMARY.md`**: Tailwind vs tokens decision for this feature.
