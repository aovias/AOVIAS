# Phase 59 — Wave 1: Drawer shell, open/close, layout sections, trigger from “Add task”

## Goal

Introduce a **right-side Create & Assign Task** surface (drawer/dialog pattern) with **five section regions** (headers + placeholders), **sticky footer** (Cancel / Save Draft / Create Task), **responsive** full-screen on small viewports, and **open** from **`quickAction('task')`** in `OeExecutionWizardComponent`. Persist **open state + draft snapshot** in `JourneyWorkspaceStore` (signals) so binding is centralized. **Auto-fill** standard/OE linkage from store when drawer opens. Styling follows **`DESIGN_RULES.md`** + tokens; **16px base spacing** via `--space-4` (or documented token alias).

## must_haves

- [ ] New **`CreateAssignTaskDrawerComponent`** (standalone) under `features/journey/components/create-assign-task-drawer/` with **OnPush**, **inputs** optional `journeyId`, `oeId` (or read store internally).
- [ ] **Store**: `taskAssignmentDrawerOpen = signal(false)`; `taskAssignmentDraft` or nested object signal for draft fields; actions **`openTaskAssignmentDrawer()`**, **`closeTaskAssignmentDrawer()`**, **`setTaskAssignmentDraft(partial)`**; **`resetTaskAssignmentDraft()`** on successful create or explicit cancel (product choice: confirm discard — optional Wave 2).
- [ ] **Wizard**: `quickAction('task')` calls `store.openTaskAssignmentDrawer()` (and initializes draft from `buildTaskDraftFromContext()` helper using `selectedOeId`, `findOe`, `oeWizardHeaderVm`, selected standard from store if available).
- [ ] **Host placement**: render drawer **once** at wizard root (or shell) — prefer **sibling overlay** in wizard template: `@if (store.taskAssignmentDrawerOpen()) { <app-create-assign-task-drawer /> }` **or** `MatDialog.open` from wizard — pick **one** pattern in implementation; document in SUMMARY.
- [ ] **Layout**: scrollable **body** + **sticky footer** with three buttons; **Cancel** closes + clears draft; **Save Draft** persists draft to `sessionStorage` key namespaced by `userId` + `journeyId` + `oeId` (mirror wizard key style); **Create Task** stub (valid form → snackbar “Task creation API not connected” or dev-only log) unless task API exists.
- [ ] **Sections** (placeholders acceptable in Wave 1): titled blocks with **Lucide icons** — (1) Task Details, (2) Assignment, (3) Classification, (4) Linkage, (5) Attachments.
- [ ] **Responsive**: CSS breakpoint — drawer width **min(440px, 100%)** desktop; **100vw × 100dvh** mobile with same footer.
- [ ] **Accessibility**: focus moves to drawer on open; **Escape** closes; **`aria-labelledby`** on dialog/panel; trap focus ( **`cdkTrapFocus`** if not using MatDialog).
- [ ] `ng build` passes.
