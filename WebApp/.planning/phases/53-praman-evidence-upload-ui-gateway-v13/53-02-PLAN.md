# Phase 53 — Wave 2: OE wizard Evidence step — state, UX, hooks (no picker, no API)

## Goal

Enhance **`OeExecutionWizardComponent`** Evidence step so the drop zone is **interactive but gated**: hover/disabled styling, tooltip, user message on click, **local state** for `selectedFiles` and `uploadMode` (`'single' | 'bulk'`), **file preview list** (name, size, status **Pending**), bulk mode label, validation feedback, and **stub hooks** `handleFileSelect`, `handleBulkSelect`, `buildSinglePayload`, `buildBulkPayload`, `triggerUpload` that use Wave 1 builders and **`console.debug`** (or structured logger **debug** in dev) **without** calling `JourneyDataService` upload methods.

## must_haves

- [ ] **Signals or private fields:** `selectedFiles: File[]` (or signal), `uploadMode: 'single' | 'bulk'` derived: `files.length &lt;= 1` → `'single'`, else `'bulk'` (or explicit toggle if UX requires — default derived).
- [ ] **Drop zone / primary click:** `(click)` and keyboard **Enter/Space** on the drop zone **prevent default file dialog** — there is **no** `<input type="file">`. Show snackbar, inline message, or `MatSnackBar`: **“Upload will be enabled shortly”**. **`matTooltip`** text: **“Upload not enabled yet”** (and `aria-describedby` or `title` fallback for a11y).
- [ ] **Simulate selection (dev-only, optional):** If implemented, guard with `ngDevMode()` and document: e.g. double-click or **temporary** `inject` of test files — **not** in production build paths. Otherwise, **`handleFileSelect` / `handleBulkSelect`** accept `File[]` for future wiring and may be **no-op** until Phase 54; minimum: public methods exist and are callable from tests.
- [ ] **`buildSinglePayload()` / `buildBulkPayload()`:** call Wave 1 `buildSingleEvidenceFormData` / `buildBulkEvidenceFormData` with **placeholder** `evidenceType` from a wizard-level constant or TODO (e.g. `'Document'`); **metadata** optional `undefined` until KB/journey VM supplies taxonomy.
- [ ] **`triggerUpload()`:** run `validateEvidenceFilesForMode` → on failure set **inline validation message**; on success build FormData, **`console.debug`** keys (or `logger.debug` behind `environment.enableDebugLogging`), **do not** call `JourneyDataService.upload*`.
- [ ] **UI:** When `selectedFiles.length &gt; 1`, show **“Bulk upload mode (X files selected)”**; list rows: name, human-readable size, **Pending** chip/text.
- [ ] **Styles:** Disabled appearance when `operationalModeUi().wizard.evidenceSection === 'readonly'` or `allStepsReadOnly` — **extend** existing `.oe-wizard__dropzone` hover/focus styles per **DESIGN_RULES** (no new raw hex); disabled cursor/`aria-disabled` on zone when read-only.
