# Plan 21-01: Route by `isOnboarded` and drive header hospitals from organization-detail

## Objective

After successful sign-in and `organization-detail` fetch, evaluate `data.hospitals[]`:

- If **any** hospital has `isOnboarded: true` → route to `/app/dashboard`
- If **none** are onboarded (or no hospitals) → route to onboarding flow

Additionally, replace hardcoded header hospital options with API-driven values from organization-detail and auto-select the onboarded hospital by default.
