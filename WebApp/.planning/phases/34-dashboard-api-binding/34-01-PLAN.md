# 34-01: Dashboard Snapshot Models & Service

## Objective
Create fully typed TypeScript interfaces for the `/dashboard/program-overview-snapshot` API response and update `DashboardService` to call the correct endpoint.

## Tasks

<task id="01" name="Create dashboard snapshot model file">
### Create typed interfaces for the full API response
**File:** `src/app/features/dashboard/models/dashboard-snapshot.model.ts` (new)

Define all interfaces matching the API response shape. The API response interceptor unwraps the envelope (`ApiResponse<T>` → `T`), so these models represent the `data` payload only.

```typescript
export interface DashboardSnapshot {
  tenantId: string;
  organizationName: string;
  generatedAt: string;
  snapshotRange: SnapshotRange;
  summary: SnapshotSummary;
  frameworks: FrameworkSnapshot[];
  hospitals: HospitalSnapshot[];
  scoreTrends: ScoreTrend[];
  tasksSummary: TasksSummary;
  milestones: MilestoneSnapshot[];
  alerts: AlertSnapshot[];
  filters: SnapshotFilters;
}

export interface SnapshotRange {
  from: string;
  to: string;
}

export interface SnapshotSummary {
  totalHospitals: number;
  onboardedHospitals: number;
  totalJourneys: number;
  activeJourneys: number;
  upcomingExpiries: number;
  overdueTasks: number;
  completionRate: number;       // 0.0–1.0 decimal
  avgComplianceScore: number;   // 0–100
  frameworksActive: number;
}

export interface FrameworkSnapshot {
  frameworkCode: string;
  frameworkName: string;
  activeHospitals: number;
  journeys: number;
  avgScore: number;
  statusCounts: Record<string, number>;
  upcomingMilestones: MilestoneSnapshot[];
  recentActivity: ActivitySnapshot[];
}

export interface ActivitySnapshot {
  activityId: string;
  type: string;
  actor: string;
  createdAt: string;
  summary: string;
}

export interface HospitalSnapshot {
  hospitalId: string;
  name: string;
  code: string;
  isOnboarded: boolean;
  nabhLevel: string | null;
  openTasks: number;
  overdueTasks: number;
  lastUpdated: string;
  journeys: JourneySnapshot[];
}

export interface JourneySnapshot {
  journeyId: string;
  frameworkCode: string;
  frameworkName: string;
  startDate: string | null;
  expiryDate: string | null;
  status: string;
  score: number;
  progressPercent: number;
}

export interface ScoreTrend {
  date: string;
  avgScore: number;
  frameworks: Record<string, number>;
}

export interface TasksSummary {
  total: number;
  open: number;
  overdue: number;
  dueSoon: number;
  byPriority: Record<string, number>;
  byType: Record<string, number>;
  byFramework: TasksByFramework[];
}

export interface TasksByFramework {
  frameworkCode: string;
  open: number;
  overdue: number;
}

export interface MilestoneSnapshot {
  milestoneId: string;
  title: string;
  frameworkCode?: string;
  owner?: string;
  dueDate: string;
  status: string;
}

export interface AlertSnapshot {
  alertId: string;
  type: string;
  severity: string;
  message: string;
  entityType: string;
  entityId: string;
  createdAt: string;
  acknowledged: boolean;
}

export interface SnapshotFilters {
  frameworks: string[];
  hospitals: FilterHospital[];
  dateRange: { from: string; to: string };
}

export interface FilterHospital {
  hospitalId: string;
  name: string;
}
```

### Verification
- [ ] All interfaces match the sample API response shape exactly.
- [ ] No `any` types used.
- [ ] `completionRate` documented as 0–1 decimal (not percentage).
- [ ] File exports all interfaces.

### Update `DashboardService` to call the snapshot endpoint with typed return
**File:** `src/app/features/dashboard/services/dashboard.service.ts`

```typescript
import { Injectable } from '@angular/core';
import { Observable } from 'rxjs';
import { BaseApiService } from '../../../shared/services/base-api.service';
import { DashboardSnapshot } from '../models/dashboard-snapshot.model';

@Injectable({
  providedIn: 'root',
})
export class DashboardService extends BaseApiService {
  getProgramOverviewSnapshot(): Observable<DashboardSnapshot> {
    return this.get<DashboardSnapshot>('/dashboard/program-overview-snapshot');
  }
}
```

### Verification
- [ ] Endpoint is `/dashboard/program-overview-snapshot`.
- [ ] Return type is `Observable<DashboardSnapshot>`.
- [ ] Old `getDashboardData()` removed (unused).
- [ ] Import path to model is correct.
</task>
