# Plan 01 — OE wizard UX specification & design rules

## Goal (phase)

Lock the **authoritative UX, IA, and behavioral spec** for the OE full-screen wizard (structure, steps, locking, context panel, responsive, a11y, tokens) and reflect it in **`DESIGN_RULES.md`** so implementation (Plan 02) cannot drift.

## must_haves

- [ ] **`44-DESIGN-SPEC.md`** reviewed and accepted as the single UX source (full modal structure, four regions, five steps with CTAs, smart locking table, responsive matrix, a11y expectations).
- [ ] **`DESIGN_RULES.md`** gains a **Journey — OE Execution Wizard** section: entry point (Context Panel CTA), overlay shell rules, stepper naming, **forbidden** patterns (small centered dialog, hardcoded visuals), cross-links to tokens + scrollbar utilities for scroll areas.
- [ ] **Step locking rules** documented in plain language matching the brief (Evaluate after minimum execution; Improve conditional; Complete gating).
- [ ] **No code-level values** in the spec documents (no hex/px literals).
