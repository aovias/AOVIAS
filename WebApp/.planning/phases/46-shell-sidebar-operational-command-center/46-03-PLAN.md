# Plan 03 — Collapsed rail, quick actions, responsiveness, accessibility, scalability

## Goal (phase)

Complete the **operational command center** experience: **expanded vs collapsed** sidebar with **smooth transition**, **tooltips** / **accessible names** for icon-only mode, **Quick actions** strip, **scroll** behavior with **sticky** brand/context zones, **mobile overlay** parity with **hamburger**, **keyboard** and **focus** excellence, and **documented** extension pattern for **50+** modules.

## must_haves

- [ ] **Collapsed mode**: icons only; **full labels** on expand; **width state** persisted across sessions (mechanism in implementation — localStorage or user prefs API).
- [ ] **Tooltips** on collapsed hover/focus; **aria-expanded** / **aria-label** on toggle; **no** tooltip-only accessible name.
- [ ] **Quick actions** region: compact **icon buttons** with text available (tooltip + `aria-label`); actions: **Add Task**, **Upload Evidence**, **Create Finding** (or route to creation flows); does not push primary nav below fold on typical laptop heights.
- [ ] **Scroll**: sidebar body scrolls; **brand** + **context** (and optionally quick actions) **sticky** OR context scrolls with nav based on **one** coherent pattern — document choice.
- [ ] **Responsive**: desktop full width; **tablet** reduced width variant without hiding labels (unless collapsed user preference); **mobile** overlay drawer + **backdrop** + **body scroll lock** (existing service behavior preserved/enhanced).
- [ ] **Keyboard**: `↑`/`↓` or Tab through nav; **Escape** closes mobile drawer; **focus trap** in drawer when open.
- [ ] **prefers-reduced-motion**: respect for width/opacity transitions.
- [ ] **Scalability**: **nested** items and **feature-flagged** rows documented; **max section size** guidance (split into subsections when > ~8 items).
