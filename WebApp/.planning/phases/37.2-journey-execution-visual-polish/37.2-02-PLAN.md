# 37.2-02: Left column — chapter navigation card treatment

## Objective

Convert chapter rows into **clear card-like items** with **strong active state**, **visible risk cues**, **prominent progress**, and **hover feedback**—refining only markup/CSS structure as needed; **no** change to search/sort behavior or emitted events.

## Preconditions

- `ExecutionScreenComponent` uses **`execution-chapter-panel` only**; chapter rows are **inline** in its template (`.chapter-item` BEM). Do **not** edit standalone `chapter-item/` or `chapter-navigation/` unless a future refactor extracts shared markup (out of scope for 37.2).

## Tasks

<task id="01" name="Card row structure">
- Wrap each chapter row in a clear **card container** (BEM blocks): padding, radius, border, background from tokens.
- Increase **vertical spacing between items** using `--space-*`.

**must_haves:**
- Each chapter is visually distinct from its neighbors.
- Selected chapter: border and/or background emphasis using semantic tokens (reuse existing “active” patterns from 37.1 if present).
</task>

<task id="02" name="Risk and progress emphasis">
- Strengthen **risk rail / badge** contrast while staying token-compliant.
- Make **progress** (track + fill) more scannable—height, spacing, label proximity—without changing underlying percent values.

**must_haves:**
- Risk and progress are noticeable in a quick scan.
</task>

<task id="03" name="Interaction feedback">
- Add/refine **:hover** and **:focus-visible** for chapter rows (keyboard parity).
- Ensure hit targets meet minimum comfortable size using padding tokens, not magic numbers in TS.

**must_haves:**
- Interactive rows feel clickable; focus outline visible.
</task>

## Verification criteria

- [ ] Left panel matches “tertiary but clear” hierarchy from research (muted vs center).
- [ ] No new business logic in `.ts` files; OnPush preserved.
- [ ] `trackBy` retained or added for chapter list if missing.

## must_haves (goal-backward)

- Chapter navigation matches **card-based reference structure** and improves scanability.
