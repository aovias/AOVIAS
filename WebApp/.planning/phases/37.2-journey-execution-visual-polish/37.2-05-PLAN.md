# 37.2-05: Quality gate — a11y, performance, verification

## Objective

Cross-cut validation: **no inline styles**, **token compliance**, **`trackBy`** on execution lists, **OnPush** unchanged, **focus-visible** sanity check, build + lint on touched files, and documentation updates (`37.2-VERIFICATION.md`, refresh `37.1-UAT.md` T7 if applicable).

## Tasks

<task id="01" name="Performance and change detection">
- Audit `*ngFor` in execution screen and execution panel components; ensure `trackBy` for chapters, standards, OEs where lists can re-render.
- Confirm `ChangeDetectionStrategy.OnPush` on touched components; avoid introducing new impure pipes.

**must_haves:**
- No unnecessary list re-render patterns introduced.
</task>

<task id="02" name="Accessibility sweep">
- Verify interactive elements: chapter rows, standard headers, OE rows, buttons retain keyboard operation.
- Spot-check `aria-expanded`, table/list `aria-label` / headers per existing patterns.

**must_haves:**
- No a11y regressions vs pre-37.2 behavior.
</task>

<task id="03" name="Token and style gate">
- Grep touched files for inline `style=` and raw `#` / `\d+px` in SCSS (excluding token definition files).
- Confirm new semantic variables live only in `theme.tokens.css` / `design-tokens.scss`.

**must_haves:**
- DESIGN_RULES compliance on touched execution feature files.
</task>

<task id="04" name="Verification artifacts">
- Create/update `37.2-VERIFICATION.md` with must-have checklist and result.
- Update `37.1-UAT.md` T7 note if subjective parity improved (or point to new screenshot pair).

**must_haves:**
- Planning artifacts reflect outcome for human signoff.
</task>

## Verification criteria

- [ ] `npm run build` passes.
- [ ] `37.2-VERIFICATION.md` documents pass/fail for each must-have.
