# 37.2-03: Center column — standards + OE workspace polish

## Objective

Make the **center panel the visual anchor**: distinct **standard cards** with a strong header row (code, title, score, classification, expand control), and an **expanded OE list** that reads as separated rows with **aligned actions** and **status prominence**—refactor-only, no VM/store changes.

## Preconditions

- Standards and OE UI live **inside** `execution-standards-panel` (`.standard-card`, `.oe-item`, `.oe-table-head`). Standalone `standard-card/` / `oe-table/` / `oe-row/` packages are **not** used by the execution screen; do not edit them for this phase.

## Tasks

<task id="01" name="Standards header block">
- Refine **hero** area (compliance %, risk chip, open issues) spacing and type scale for clearer **label vs value** distinction.
- Ensure subtitle/chapter line aligns to a predictable grid with the hero metrics.

**must_haves:**
- Compliance and risk read as the focal metrics.
</task>

<task id="02" name="Standard card header and expand affordance">
- Standard **card** surfaces: header vs body contrast using tokens (border, background alt, radius).
- **Expand/collapse** control: alignment on the right, consistent icon size; `aria-expanded` wired on the interactive header region.

**must_haves:**
- Expand interaction is obvious; header grid does not wrap chaotically at desktop width.
</task>

<task id="03" name="OE table as scannable list">
- Row separation: dividers, alternating subtle surface, or increased row padding—token-only.
- **Status** chips: ensure color + padding + font weight differentiate states (reuse execution status tokens).
- **View** (and similar actions): align in a dedicated column; consistent button/ghost styles.

**must_haves:**
- OE rows are easy to scan; status is not “plain text only.”
- Column alignment is consistent across rows.
</task>

<task id="04" name="Hover and row feedback">
- Hover/focus states for OE rows and standard headers (no pointer-event hacks).

**must_haves:**
- Interactive areas show clear hover/focus-visible feedback.
</task>

## Verification criteria

- [ ] Center panel clearly dominates over left/right at a glance.
- [ ] No changes to OE VM derivation rules in `execution-oe-vm.util.ts` unless purely presentational constant (prefer zero TS changes).
- [ ] `npm run build` passes.

## must_haves (goal-backward)

- **Standard → OE** hierarchy matches structured enterprise reference; table-like flatness removed.
