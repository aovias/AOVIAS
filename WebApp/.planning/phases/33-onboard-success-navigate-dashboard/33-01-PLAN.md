# 33-01: Onboard Success — Refresh Org State & Navigate to Dashboard

## Objective
After `POST /onboarding/onboard` returns 200 OK, force-reload `organization-detail` to update `isOnboarded` in cached state, then navigate to `/app/dashboard`. Currently the wizard navigates to `/control-center/compliance-command-center` which is a non-existent route.

## Research Summary

**Current behaviour (bug):**
- `ai-setup-assistant.component.ts` → `submitOnboard()` → on success:
  - Clears wizard session and sets completed flag ✓
  - Navigates to `this.router.navigate(['/control-center/compliance-command-center'])` ✗ (wrong route)
  - Does NOT refresh `organization-detail` ✗ (cached `isOnboarded: false` can cause onboarding guard to block `/app/dashboard`)

**Required behaviour:**
1. Force-reload `organization-detail` via `OrganizationService.loadOrganizationDetails(true)` so the guard cache has `isOnboarded: true`.
2. Navigate to `/app/dashboard`.

**Affected file:** `src/app/features/onboarding/pages/ai-setup-assistant.component.ts` — only the `next:` callback inside `submitOnboard()`.

**Services already available:**
- `OrganizationService` (injectable, has `loadOrganizationDetails(forceReload: boolean)`)
- `Router` (already injected in the component)

## Tasks

<task id="01" name="Fix post-onboard navigation in ai-setup-assistant">
### Update `submitOnboard()` success handler
**File:** `src/app/features/onboarding/pages/ai-setup-assistant.component.ts`

1. **Inject `OrganizationService`** (if not already injected):
   ```typescript
   private readonly organizationService = inject(OrganizationService);
   ```

2. **Replace the `next:` callback** in the `submitOnboard()` subscribe block:

   **Before:**
   ```typescript
   next: () => {
     this.submitting.set(false);
     this.onboardIdempotencyKey = null;
     this.wizard.setCompleted(true);
     this.wizard.clearWizardSession();
     this.legacyOnboardingStore.setFrameworkCodes([]);
     this.router.navigate(['/control-center/compliance-command-center']);
   },
   ```

   **After:**
   ```typescript
   next: () => {
     this.submitting.set(false);
     this.onboardIdempotencyKey = null;
     this.wizard.setCompleted(true);
     this.wizard.clearWizardSession();
     this.legacyOnboardingStore.setFrameworkCodes([]);
     // Refresh org-detail so guards see isOnboarded: true, then navigate
     this.organizationService.loadOrganizationDetails(true).subscribe({
       next: () => this.router.navigate(['/app/dashboard']),
       error: () => this.router.navigate(['/app/dashboard']),
     });
   },
   ```

   **Why both `next` and `error` navigate:** Even if the org-detail refresh fails (unlikely), the user should still land on the dashboard — the guard will re-fetch on its own if needed.

3. **Add `OrganizationService` import** if not already present at the top of the file.
