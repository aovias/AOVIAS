# 30-03: Click Target, Journey-Based Frameworks, Session Persistence & Auto-Popup

## Objective
Fix six issues with the Phase 30 implementation:
1. Only the edit/pencil icon should be clickable (not the full context-panel).
2. Framework list in the popup must come from `organization-detail.hospitals[].journey[]` — NOT `/frameworks/all-frameworks`.
3. Framework list is per-hospital: switching hospital in popup must dynamically update frameworks.
4. Store selected hospital ID + framework journey ID in `sessionStorage` (persist across navigation/refresh); clear on logout.
5. Display card framework section: show frameworkName (top) + frameworkCode (bottom) instead of org name.
6. On login, if no session selection exists, automatically show the selector popup so user picks hospital + framework.

## Research Findings

### Current Organization Model (`OrganizationHospital`)
- **File:** `src/app/core/services/organization.service.ts`
- Interface `OrganizationHospital` currently has NO `journey` field.
- Need to add `journey: HospitalJourney[]` to match the API response.

### Journey Data Shape (from API)
```json
{
  "journeyId": "a7b6b19a-...",
  "frameworkCode": "NABH-E-26",
  "frameworkName": "NABH Entry Level Accreditation",
  "startDate": null,
  "expiryDate": null
}
```

### Session Storage Pattern
- Existing pattern: `localStorage` for auth tokens/org/hospital IDs (in `SessionService`).
- Onboarding state uses `sessionStorage` with user-namespaced keys (`onboarding-storage.keys.ts`).
- For this feature: use `sessionStorage` with simple keys (`selected_hospital_id`, `selected_framework_journey_id`) — cleared on logout, survives refresh.

### Login Flow
- **File:** `src/app/login/login.component.ts`
- After login → loads `organization-detail` → sets default hospital → routes to `/app/dashboard`.
- Shell loads → `SidebarComponent.ngOnInit()` initializes hospital card.
- Popup trigger should happen in `SidebarComponent.ngOnInit()` after initialization, checking if session values exist.

### Dialog Current State
- `FrameworkSelectorItem` has `{ id, name }`.
- Need to add `code` field for display in card.
- Dialog needs to accept hospital-grouped journeys and dynamically filter frameworks when hospital selection changes.
