# 30-02: Redesign Sidebar Card + Wire Framework State

## Objective
Redesign the sidebar hospital card to be borderless with circular icon, add "Selected Framework" display section with separator, and wire framework selection through the enhanced dialog and state services.

## Reference Design
- Hospital section: circular icon (subtle bg) + hospital name (bold, large) + org name (muted) + pencil/switch icon (right, inside rounded container)
- Framework section: "Selected Framework" label (muted, small) + check/badge icon (gold/yellow) + framework name (bold) + org name (muted)
- No visible card border — seamless with sidebar background
- Thin separator line below the entire section before nav

<task id="05" name="Enhance AppContextService for dual switching">
### Update AppContextService to handle hospital + framework

**File:** `src/app/core/services/app-context.service.ts`

1. Add `switchContext(hospitalId: string, frameworkId: string)` method:
   ```typescript
   switchContext(hospitalId: string, frameworkId: string): void {
     this.logger.info('Switching context', { hospitalId, frameworkId });
     this.switchingSubject.next(true);
     this.complianceContext.setHospitalId(hospitalId);
     this.complianceContext.setFrameworkId(frameworkId);
     this.hospitalSwitchedSubject.next(hospitalId);
     this.switchingSubject.next(false);
     this.logger.info('Context switched', { hospitalId, frameworkId });
   }
   ```
2. Keep existing `switchHospital()` for backward compat (it calls `loadFrameworkForHospital` which clears framework)
