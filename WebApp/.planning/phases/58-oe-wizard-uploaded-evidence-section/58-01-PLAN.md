# Phase 58 — Wave 1: Evidence step layout + Uploaded Evidence list + download wiring

## Goal

Restructure the OE wizard **Evidence** step so it matches the reference: **Evidence required** (icon + KB copy) → bordered **Uploaded Evidence** section listing **persisted** files from the selected OE → **drop zone** → existing **pending file** queue and **Upload** actions. Implement **Download** per row using `JourneyDataService.downloadObjectiveElementEvidenceFile` and a safe client-side save. Styling is **token-only** (`DESIGN_RULES.md`, `src/styles/tokens/*`).

## must_haves

- [ ] **Reorder** Evidence step DOM: uploaded section appears **above** the drop zone; pending `File[]` list stays **below** drop zone (or directly under it) with clear visual separation from server-backed rows.
- [ ] New **Uploaded Evidence** container: title line, list or **empty state** (“No files uploaded yet” or equivalent), hairline row separators, responsive stacking on narrow widths.
- [ ] **Bind** rows to `store.findOe(store.selectedOeId()!)?.oe.evidence` (guard null OE); sort by `uploadedAt` descending if API order is not guaranteed (optional `computed` in component).
- [ ] **Row content:** primary line = `name`; secondary line = formatted `uploadedAt` (reuse project conventions — e.g. `DatePipe` with `medium`/`short` or a small formatter); right cluster = **type label** from filename extension + **omit size** OR show type only (document in SUMMARY if product insists on size later).
- [ ] **File-type affordance:** minimal variant — icon or colored badge per extension family (PDF / spreadsheet / Word / other) using existing `ng-icons`/Lucide; no new npm packages.
- [ ] **Download:** icon-only or compact button; `takeUntilDestroyed`; on success create object URL / programmatic `<a download>` with filename from `item.name`; `revokeObjectURL` after click; on error `formatEvidenceHttpError` + snackbar.
- [ ] **Read-only mode:** when `evidenceDropzoneDisabled()` is true, **disable** drop zone and pending removal/upload as today; **Download** may stay enabled for auditors (confirm in implementation; if product prefers hide download in readonly, gate with same flag).
- [ ] **No** new environment flags required; **no** new Gateway routes.
