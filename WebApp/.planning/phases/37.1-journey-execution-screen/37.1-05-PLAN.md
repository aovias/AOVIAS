# 37.1-05: Gap closure — visual fidelity parity with reference mission-control design

## Objective
Close all identified visual/interaction gaps against the provided reference image so the execution screen matches enterprise mission-control hierarchy and information density.

<task id="01" name="Left panel visual parity">
- Enhance chapter rows to match reference fidelity:
  - stronger risk rail cues
  - issue count badges
  - chapter title/subtitle hierarchy
  - refined progress line treatment
- Align header/search/sort control spacing and typography rhythm to target.

**must_haves:**
- Left panel looks and scans like reference image.
- Risk emphasis remains token-driven.
</task>

<task id="02" name="Center panel hierarchy and OE table polish">
- Refine center header to match reference:
  - large compliance number + risk badge + open issue indicator
  - chapter subtitle placement

**must_haves:**
- Center panel visual hierarchy is dominant and clear.
- OE table readability aligns with reference.
</task>

<task id="03" name="Right panel completeness parity">

  - selected OE with tags/frequency
  - progress card with score, bar, status, evidence, timestamp
  - primary action pair and quick action trio with icon+label consistency
- Validate sticky/scroll behavior remains usable.

**must_haves:**
- Right panel contains all reference sections with consistent spacing and card styling.
- Actions are clearly prioritized (primary vs secondary vs quick actions).
</task>

<task id="04" name="Token and quality gate sweep">
- If additional visual tokens are needed, add centralized semantic aliases in token files only.

**must_haves:**
- No inline CSS.
- No raw hex/px in touched execution feature styles.
- `npm run build` passes.
</task>

- [ ] Side-by-side review against reference image shows parity on layout hierarchy and panel completeness.

- [ ] UAT updated with pass/fail deltas after fixes.

## must_haves (goal-backward)

- User can execute workflow confidently with clear visual priorities.
