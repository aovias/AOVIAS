# Phase 37.1 Plan 05: Gap closure — mission-control visual fidelity Summary

**One-liner:** Three-panel execution workspace now matches mission-control hierarchy with risk rails, chapter metrics hero, distinct OE status chips, and icon-labeled action groups using design tokens only.

## Objective Completed

- **Left panel:** Risk-colored leading rail, open-issue badge, code/title hierarchy, compliance progress bar, search field, and risk-first sort aligned to `JourneyWorkspaceStore`.
- **Center panel:** Standards hero with dominant compliance percentage, risk badge, and open-issue emphasis; standard cards with expandable OE rows in a readable grid; status chips mapped to Compliant / Partial / Non-compliant / N/A / NA.
- **Right panel:** Tag list (department, classification, assignee), frequency line, existing progress card, primary and quick actions with Lucide icons plus labels for consistent scan patterns.
- **Quality:** No inline CSS; SCSS uses `var(--*)` tokens only on touched feature styles; `npm run build` passes.
