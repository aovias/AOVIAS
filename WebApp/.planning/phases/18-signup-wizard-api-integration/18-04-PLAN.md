  <action>
    1. Create private method `handleError(error: HttpErrorResponse): void`
    2. Map error status codes to user-friendly messages:
       - 400/409 with "email" in message → "Admin email already exists"
       - 400/409 with "code" in message → "Hospital code already registered"
       - 500+ → "Unable to complete onboarding. Please try again."
       - 0 (network error) → "Network error. Please check your connection."
       - Default → "Unable to complete onboarding. Please try again."
    3. Show error via `notificationService.showError(message)`
    4. Log error via `logger.error('Onboarding failed', error)` (never log password)
  </action>
  <verify>
