# 35-06: Journey API — Service, DTOs, Mapper & Cache

## Objective
Replace the **mock-first** `JourneyDataService` (`of(fixture)` + `JOURNEY_WORKSPACE_FIXTURE`) with **real HTTP** calls to backend routes under **`/Journeys/*`** (relative to `environment.apiBaseUrl`, which already includes `/api/v1`). Introduce **typed API DTOs**, a **defensive mapper** (`API → JourneyWorkspaceSnapshot` and nested models), **snapshot caching**, and **journeyId resolution** aligned with app context. **Do not** change backend contracts or UI templates.

## API routes (authoritative for this execution)

Implement constants in the service (single place to fix casing/path drift):

| Operation | Method | Route | Notes |
|-----------|--------|-------|--------|
| Workspace snapshot | `GET` | `/Journeys/workspace` | Query: `journeyId={guid}` |
| Update OE | `PATCH` | `/Journeys/objective-elements/{oeId}` | Body: partial OE fields per backend |
| List / upload evidence | `GET` / `POST` | `/Journeys/objective-elements/{oeId}/evidence` | POST body / multipart per backend |
| History | `GET` | `/Journeys/objective-elements/{oeId}/history` | |

> If live Swagger differs only in casing (`journeys` vs `Journeys`) or segment order, **adjust the constant only** — no UI changes.

**Interceptor:** `apiResponseInterceptor` unwraps `ApiResponse<T>` to `T`; service typings target **data payload** after unwrap.

- `mapApiToWorkspaceSnapshot(dto: JourneyWorkspaceApiDto): JourneyWorkspaceSnapshot`

<task id="03" name="JourneyDataService — HTTP implementation">
### Methods
- `getJourneyWorkspace(journeyId: string): Observable<JourneyWorkspaceSnapshot>`  
  - `this.get<JourneyWorkspaceApiDto>('/Journeys/workspace', { journeyId })` then `map(mapApiToWorkspaceSnapshot)` via `pipe(map(...))`.
- `patchObjectiveElement(oeId: string, body: PatchOeBody): Observable<ObjectiveElement | void>`  
  - `PATCH /Journeys/objective-elements/{oeId}` — return type matches backend (prefer mapped `ObjectiveElement` or minimal patch result).
- `getEvidence(oeId)`, `uploadEvidence(oeId, ...)` — GET/POST as per backend (set `HttpHeaders` / `FormData` if multipart).
- `getObjectiveElementHistory(oeId)` — GET history list; map to `OeHistoryEvent[]`.

### Cache
- Keep `getWorkspaceCached()` with `shareReplay(1)` but base it on **HTTP** observable.
- `clearWorkspaceCache()` on hospital/framework switch: call from journey page `ngOnInit` (already clears) and subscribe to `AppContextService.hospitalSwitched$` / framework changes if needed so cache does not serve wrong tenant.

### Errors
- Use `catchError` only where the service translates to user-safe messages; prefer **letting errors propagate** to store for centralized UX (35-07).

**must_haves:**
- Remove `JOURNEY_WORKSPACE_FIXTURE` import and **delete** `journey-workspace.fixture.ts` when no longer referenced.
- No `of(mock)` left in production code paths.
</task>

**must_haves:**
