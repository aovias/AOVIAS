# 35-04: OE Detail Drawer, NA Flow, Action Plans & Evidence Tab

## Objective
Deliver **OE detail** surface (drawer or full-width modal per UX choice), **NA toggle with mandatory justification**, **action plan list** for low scores, **evidence** integration (OE-scoped list, verification, expiry, upload/preview hooks), **audit remarks**, **history timeline**, and **score rationale** section.

## Tasks

<task id="01" name="OeDetailDrawerComponent">
### Drawer (Material sidenav `position="end"` or CDK overlay)
- Sections: full description, score rationale, evidence list, audit remarks, action plans, history timeline.
- **Close** preserves selection state; **no** full page navigation.
- **Lazy load** heavy subsections (timeline) on tab activate.

**must_haves:**
- Focus trap + ESC close.
- Theme tokens for background/border.
</task>

<task id="02" name="NA + justification">
### Toggle NA on OE
- If `isNa` true → require justification text before save (reactive form validation).
- **Block save** when NA without justification (spec).
- Visual: muted card style for NA OEs in list (drawer + card).

**must_haves:**
- Error message accessible (`aria-live`).
</task>

<task id="03" name="ActionPlanListComponent">
### List for OE when score ≤ 3 or when plans exist
- Columns: title/summary, owner, deadline, status (Open/Closed).
- Empty state: “No action plans” with CTA if permitted.

**must_haves:**
- Data from `ObjectiveElement.actionPlans[]` or separate API call stub — typed.
</task>

<task id="04" name="JourneyEvidenceTabComponent">
### Evidence tab (within journey or sub-route)
- OE-wise grouping or filter; verification status; expiry column.
- **Upload** + **preview** — integrate existing `shared` file-upload if present; else placeholder button calling service.
- **Read-only** mode when store says lifecycle read-only.

**must_haves:**
- No clause terminology.
- Links to evidence detail if API provides id.
</task>

<task id="05" name="History timeline">
### Timeline component (reuse pattern from old journey if any)
- Events: audit, evidence, task, action plan — **mock** structured data first.

**must_haves:**
- Chronological sort (newest first).
</task>

## Verification criteria
- [ ] Open OE → drawer shows; close → returns to list.
- [ ] NA toggle blocks save without justification.
- [ ] Action plans visible for score ≤ 3 mock OE.

## must_haves
- **Evidence** and **audit** sections present in drawer.
- **Clause** references **removed** from strings.
