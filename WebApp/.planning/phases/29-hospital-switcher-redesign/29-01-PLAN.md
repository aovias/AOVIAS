## Objective

Remove the hospital selector dropdown and framework selector dropdown from the header component. Rebalance the header layout so only the logo remains on the left and user controls (theme toggle, notifications, profile) stay on the right.

## Context

The header currently contains a `.hierarchy-selectors` section with two dropdown selectors (hospital + framework) between the logo and the right-side controls. These are being replaced by a new sidebar-integrated hospital switcher (Plans 29-02 and 29-03). This plan cleanly removes the old selectors and all their associated code.

## Tasks

<task id="29-01-01" title="Remove hospital & framework selector template markup">
**File:** `src/app/core/layout/header.component.ts`

Remove the entire `<div class="hierarchy-selectors">` block from the template (lines 50–138 in current file). This includes:
- The hospital selector wrapper (`selector-button`, `selector-dropdown` with hospital list)
- The `.divider` element
- The framework selector wrapper (button + dropdown)

After removal, the `header-left` div should contain only the `.logo.header-logo` element.
</task>

<task id="29-01-03" title="Remove hospital & framework selector component logic">
**File:** `src/app/core/layout/header.component.ts`

Remove from the component class:
- **Signals:** `hospitalMenuOpen`, `frameworkMenuOpen`, `selectedHospital`, `selectedOrganization`, `selectedFramework`, `hospitals`
- **Properties:** `frameworks` array
- **Methods:** `toggleHospitalMenu()`, `toggleFrameworkMenu()`, `selectHospital()`, `selectFramework()`
- **Lifecycle:** Remove `ngOnInit()` and its call to `initializeHospitals()`
- **Private methods:** `initializeHospitals()`, `applyOrganizationHospitals()`

</task>
