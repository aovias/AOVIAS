# 36-01: Domain alignment, mock data, and store initialization

## Objective
Align domain types with **Framework → Chapters → Standards → ObjectiveElements** per **NABH Hospital 6th Edition (effective 1 Jan 2025)** — official **10 chapter codes** (AAC … IMS), **100** standards / **639** OEs in full catalog — introduce **`mockJourneyData.ts`** + mapper to **`JourneyWorkspaceSnapshot`**, add **edition metadata** (`standardEdition`, `effectiveFrom`, optional `oeCatalogVersion`), replace **`loadWorkspace()`** with **`loadMockData()`** (no HTTP), and extend **`JourneyWorkspaceStore`** with **standard-centric** navigation: **`selectedStandard`**, **`objectiveElementsForSelectedStandard`**, **`selectStandard(id)`**, default selection (first chapter → first standard).

## Tasks

<task id="01" name="Domain model tweaks">
### Refactor models
- **`ComplianceStandard`**: add `chapterId: string`; add `title: string` (use for display; map from mock or duplicate `code` + short name if needed); keep `description`, `objectiveElements`.
- **`ObjectiveElement`**: add `standardId: string` (explicit parent link; populate in mock + mapper).
- **`JourneyChapter`**: unchanged structurally; ensure every chapter in mock has **≥1** standard.
- If numeric API-style `Classification` is required for derivation, add **parallel** `OeClassificationNumeric` enum or extend `nabh.enums.ts` without breaking existing `OeClassification` string union — **mapper** converts mock numeric → existing string union for UI.

**must_haves:**
- No `Clause` types.
- Every OE in mock has `standardId`, valid `code` (e.g. `AAC.1.a`), classification assigned.
</task>

<task id="02" name="mockJourneyData + mapper">
### Add `src/app/features/journey/data/mock-journey-data.ts`
- Export **`MOCK_JOURNEY`** (or `MOCK_WORKSPACE_BY_JOURNEY_ID: Record<string, …>`) with nested structure: `chapters[].code` using **official codes** (**AAC, COP, MOM, PRE, IPC, PSQ, ROM, FMS, HRM, IMS**); `standards[].code`, `objectiveElements[]` with **`classification`** matching PDF bands (Core/Commitment/Achievement/Excellence).
- **Demo scope:** May ship a **representative subset** of OEs for UI performance; snapshot must include **`catalogSummary`** or metadata noting `totalOesExpected: 639`, `chaptersExpected: 10` so the UI does not imply the mock is the full guidebook.
- Add **`mock-journey.mapper.ts`**: map mock DTO → **`JourneyWorkspaceSnapshot`** (reuse snapshot fields: `frameworkName` e.g. “NABH Hospital”, `frameworkCode`, accreditation, overview, trends — align **`accreditation`** inputs with **`36-02`** decision engine when available).

**must_haves:**
- `ng build` succeeds.
- Chapter **codes** match NABH 6th ed. naming — no invented chapter IDs that conflict with AAC…IMS.
</task>

<task id="03" name="JourneyDataService strip or mock-only">
### Remove HTTP dependencies for workspace
- **Option A (preferred):** Delete `JourneyDataService` usage from store; replace with **`JourneyMockDataService`** or **`loadMockSnapshot(journeyId: string): JourneyWorkspaceSnapshot`** in a small injectable that reads `MOCK_JOURNEY` / map.
- **Option B:** Keep file name but **remove** `BaseApiService` extension and all `get`/`patch` to `/Journeys/*`; only expose snapshot from mock.
- Remove or stub **`patchObjectiveElement`**, evidence upload HTTP, history HTTP — **store** must not subscribe to them in Phase 36.

**must_haves:**
- `grep` under `features/journey/` shows **no** `/Journeys/workspace` or `OE_BASE` HTTP calls in production paths.
</task>

<task id="04" name="JourneyWorkspaceStore">
### Store refactor
- Replace **`loadWorkspace`** with **`loadMockData()`** (or `loadMockData(journeyId)`): sets `_snapshot` from mock mapper; clears `loadError` on success.
- Add **`selectStandard(standardId: string)`**: sets `selectedStandardId`, clears `selectedOeId` unless still valid under new standard; updates `selectedChapterId` if standard belongs to a chapter (derive chapter from standard id via lookup).
- **`selectChapter`**: set chapter + **first standard** in that chapter as selected (or null if none).
- Computed: **`selectedStandard`** (`ComplianceStandard | null`), **`objectiveElementsForSelectedStandard`** (filtered/sorted via existing `filterOesByLifecycle` + `sortOesByCode`).
- **`initFromRoute`**: resolve `journeyId` — if missing, use **default mock id** or **first key** in mock map so page still loads offline.
- Remove **`submitObjectiveElementPatch`** API calls — replace with **local-only** `patchObjectiveElement` / optional `applyLocalOePatch` for UI demos.

**must_haves:**
- `selectedStandardId` is the **primary** context for main panel OE list.
- No RxJS subscriptions to PATCH in store.
</task>
