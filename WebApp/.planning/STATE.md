## Decisions Made

- Using Angular Standalone Architecture (no NgModules)
- State management via RxJS BehaviorSubjects (no NgRx)
- All APIs must be typed
- Gateway API pattern with envelope responses
- Tokens stored in localStorage
- Journey execution OE chip labels: “Partial” when compliant with score ≤ 3; full “Compliant” when score is higher (see `execution-oe-vm.util.ts`).

## Architecture Principles

- Modular and clean code
- Enterprise scalable design
- Feature-based folder structure
- Core infrastructure separate from features
- Shared components reusable across features
